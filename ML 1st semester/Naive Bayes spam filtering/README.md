## Наивный байесовский классификатор

### Идея

Наивный Байес — алгоритм обучения с учителем, основанный на **теореме Байеса**. Вместо поиска границы между классами он оценивает, **насколько вероятно** увидеть данный набор слов в письме каждого класса, и выбирает класс с наибольшей вероятностью.

Слово «наивный» относится к упрощающему предположению: при известном классе слова письма считаются **условно независимыми** друг от друга. Это не соответствует реальному языку, но позволяет заменить сложную совместную вероятность простым произведением вероятностей отдельных слов. Благодаря этому алгоритм не требует больших выборок, быстро обучается и хорошо подходит для фильтрации текстов.

### Теорема Байеса для письма

Письмо — это набор слов $A_1, A_2, \dots, A_n$. Класс $H_i$: $H_с$ — спам, $H_н$ — не спам. По теореме Байеса:

$$P(H_i \mid A_1,\dots,A_n)=\frac{P(H_i)\cdot P(A_1,\dots,A_n \mid H_i)}{P(A_1,\dots,A_n)}$$

Знаменатель одинаков для обоих классов и на выбор не влияет, поэтому его отбрасывают. С учётом «наивного» предположения получается правило классификации:

$$\hat{H}=\arg\max_{i}\ P(H_i)\prod_{j=1}^{n}P(A_j \mid H_i)\qquad(1)$$

### Из чего состоит формула

| Величина | Формула | Смысл |
| -------- | ------- | ----- |
| Априорная вероятность класса | $P(H_i)=\dfrac{n_i}{n}$ | Доля писем класса $i$ в обучающей выборке |
| Условная вероятность слова | $P(A_j \mid H_i)=\dfrac{N_{ij}+a}{N_i+a\cdot V}$ | Вероятность встретить слово $A_j$ в письме класса $i$ |

Здесь:

- $n_i$ — число писем класса $i$, $n$ — общее число писем;
- $N_{ij}$ — сколько раз слово $A_j$ встретилось во всех письмах класса $i$;
- $N_i$ — общее число слов (с повторами) во всех письмах класса $i$;
- $V$ — размер словаря, то есть число уникальных слов в обучающей выборке;
- $a$ — параметр сглаживания, $a\in(0;1]$. При $a=1$ сглаживание называется **сглаживанием Лапласа**.

### Зачем нужно сглаживание

Если слово ни разу не встретилось в письмах какого-то класса, его вероятность $N_{ij}/N_i$ равна нулю. Тогда обнуляется всё произведение в формуле (1), и одно слово, не встречавшееся в письмах класса, «убивает» гипотезу целиком. Добавка $a$ в числителе и $a\cdot V$ в знаменателе гарантирует, что вероятность любого слова, в том числе нового, будет строго положительной, а сумма вероятностей по словарю по-прежнему равна 1.

### Переход к логарифмам

Произведение десятков малых вероятностей даёт очень маленькое число, и на практике оно может выйти за пределы точности `float`. Поэтому вместо (1) считают сумму логарифмов (логарифм монотонен, поэтому класс с максимальным значением не меняется):

$$\hat{H}=\arg\max_{i}\left[\log_2 P(H_i)+\sum_{j=1}^{n}\log_2 P(A_j \mid H_i)\right]\qquad(2)$$

Оба значения получаются отрицательными. Побеждает класс, у которого сумма **ближе к нулю** (то есть больше).

## Алгоритм по шагам

1. **Подготовка текста.** Письмо приводится к нижнему регистру, из него удаляются знаки препинания, числа и стоп-слова (предлоги, союзы, междометия и т. п.). На выходе остаётся список значимых слов.
2. **Обучение: подсчёт частот.** По письмам каждого класса считается, сколько раз встретилось каждое слово. Из этого получаются $N_{ij}$, $N_i$ и $V$.
3. **Априорные вероятности.** Вычисляются $P(H_с)$ и $P(H_н)$ как доли писем каждого класса.
4. **Вероятности слов.** Для каждого слова словаря по формуле со сглаживанием считаются $P_с(A_j)$ и $P_н(A_j)$ (Таблица 2).
5. **Разбор тестового письма.** Тестовое сообщение проходит ту же подготовку, что и обучающие. Слова, которых нет в словаре, получают вероятность $\dfrac{a}{N_i+a\cdot V}$ — именно для них нужно сглаживание.
6. **Вычисление оценок.** По формуле (2) считаются $\log_2 P(\text{спам}\mid\text{письмо})$ и $\log_2 P(\text{не спам}\mid\text{письмо})$.
7. **Решение.** Письмо относится к тому классу, у которого оценка больше.

## Задача и данные

Определить, является ли спамом письмо:

> «До конца дня открыта запись на аудит информационной безопасности со специальными условиями»

Обучающая выборка — 6 писем (по 3 в каждом классе):

| № | Спам | Не спам |
| - | ---- | ------- |
| 1 | Только до конца дня – комплексный аудит информационной безопасности по суперцене. | Сообщаем об обновлении корпоративной политики информационной безопасности. |
| 2 | Внимание! Согласно новым требованиям, ваш сертификат по информационной безопасности утратил силу. | Направляем результаты планового информационной безопасности аудит за III квартал 2025 года. |
| 3 | Раскрываем рабочий метод обхода многофакторной аутентификации, который используют профессионалы. | Открыта регистрация на внутренний курс «Основы криптографии для специалистов информационной безопасности». |

Все письма из одной тематики (информационная безопасность), поэтому решение принимается по характерным «рекламным» и «служебным» словам, а не по теме.

## Программа

Программа `lab_5.py` — линейный скрипт без отдельных функций, кроме `tokenize`.

| Блок | Что делает |
| ---- | ---------- |
| `stop_words` | Множество слов, которые не несут смысла для классификации (предлоги, союзы, междометия, `iii`, `2025`) |
| `tokenize` | Приводит текст к нижнему регистру, удаляет пунктуацию, числа и стоп-слова, возвращает список слов |
| `Counter` | Считает частоты слов отдельно для спама и не спама |
| `word_counts` | Словарь `слово → (кол-во в спаме, кол-во в не спаме)` для всех уникальных слов выборки |
| `N_spam`, `N_ham`, `V` | Общее число слов в каждом классе (**с повторами**) и размер словаря |
| `p_spam`, `p_ham` | Вероятности слова с учётом сглаживания Лапласа, `a = 1` |
| `log_P_spam`, `log_P_ham` | Итоговые оценки по формуле (2) для тестового письма |

## Результаты

**Параметры модели.** Всего в выборке 50 значимых слов: $N_с=27$ в спаме и $N_н=23$ в не спаме. Размер словаря $V=41$, сглаживание $a=1$. Классы равновероятны: $P(H_с)=P(H_н)=\dfrac{3}{6}=\dfrac{1}{2}$.

**Тестовое письмо** после подготовки превращается в 9 слов: `конца`, `дня`, `открыта`, `запись`, `аудит`, `информационной`, `безопасности`, `специальными`, `условиями`. Слова `до`, `на`, `со` отброшены как стоп-слова.

Знаменатели для вероятностей слов: $N_с+V=27+41=68$ для спама и $N_н+V=23+41=64$ для не спама.

| Слово | Кол. в спаме | Кол. в не спаме | $P_с(A_j)$ | $P_н(A_j)$ |
| ----- | :---: | :---: | :---: | :---: |
| конца | 1 | 0 | 0,0294 | 0,0156 |
| дня | 1 | 0 | 0,0294 | 0,0156 |
| открыта | 0 | 1 | 0,0147 | 0,0312 |
| запись | 0 | 0 | 0,0147 | 0,0156 |
| аудит | 1 | 1 | 0,0294 | 0,0312 |
| информационной | 2 | 3 | 0,0441 | 0,0625 |
| безопасности | 2 | 3 | 0,0441 | 0,0625 |
| специальными | 0 | 0 | 0,0147 | 0,0156 |
| условиями | 0 | 0 | 0,0147 | 0,0156 |

Слова `запись`, `специальными` и `условиями` в обучающей выборке не встречались, их вероятности получены только за счёт сглаживания.

**Оценки классов** по формуле (2):

$$\log_2 P(\text{спам}\mid\text{письмо})=\log_2\tfrac12+3\log_2 0{,}0294+4\log_2 0{,}0147+2\log_2 0{,}0441\approx-49{,}617$$

$$\log_2 P(\text{не спам}\mid\text{письмо})=\log_2\tfrac12+5\log_2 0{,}0156+\log_2 0{,}0312+\log_2 0{,}0312+2\log_2 0{,}0625\approx-49{,}000$$

(во втором выражении `открыта` и `аудит` имеют одинаковую вероятность $0{,}0312$, а слов с $0{,}0156$ пять: `конца`, `дня`, `запись`, `специальными`, `условиями`.)

**Вывод.** Так как $-49{,}617<-49{,}000$, вероятность класса «не спам» выше, поэтому письмо относится к **не спаму**. Перевес небольшой — около 0,6 бита, то есть примерно в 1,5 раза.

Что повлияло на решение:

- **В пользу спама** — слова `конца` и `дня`, которые в обучающей выборке встречались только в спаме (примерно по 0,9 бита каждое).
- **В пользу не спама** — слово `открыта` (около 1,1 бита), а также `информационной` и `безопасности` (по 0,5 бита): в обычных письмах они встречаются чаще.
- **Почти нейтральные** — `запись`, `аудит`, `специальными`, `условиями`. Каждое даёт не спаму лишь около 0,09 бита из-за того, что знаменатель для него меньше (64 против 68).

## Ограничения

- Предположение о независимости слов — упрощение. Например, `информационной` и `безопасности` почти всегда идут парой, и модель считает их независимыми, чем завышает их общий вес.
- Выборка из 6 писем слишком мала для надёжной оценки. Один-два слова легко меняют итог, а разница между оценками здесь невелика.
- Скрипт считает $V$ только по обучающей выборке и не увеличивает его на число новых слов тестового письма. В классической схеме их добавляют в словарь ($V=44$). Оценки тогда равны $-50{,}178$ и $-49{,}595$, вывод не меняется.
- Модель не учитывает порядок слов, формы слов (нет лемматизации: `аудит` и `аудита` — разные слова) и контекст.
