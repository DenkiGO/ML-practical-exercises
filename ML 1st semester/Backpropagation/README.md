## Метод обратного распространения ошибки

### Идея

**Backpropagation** — основной алгоритм обучения нейронных сетей. Он отвечает на вопрос: *как нужно изменить каждый вес, чтобы ошибка сети уменьшилась?* Ответ даёт **градиент** функции ошибки по весам: он показывает направление, в котором ошибка растёт быстрее всего. Если сдвинуть веса в противоположную сторону, ошибка уменьшится. Это и есть **градиентный спуск**.

Сеть — это композиция функций (слоёв):

$$y=f_n\bigl(f_{n-1}(\dots f_2(f_1(x)))\bigr)$$

Чтобы найти градиент такой композиции, применяют **правило цепочки**: производная сложной функции равна произведению производных её звеньев. Название метода связано с порядком вычислений: сначала сигнал идёт вперёд (от входов к выходу), потом ошибка «возвращается» назад (от выхода к весам), и на каждом шаге производные перемножаются.

### Модель в лабораторной работе

В работе используется простейшая сеть — **один нейрон** с двумя входами:

| Величина | Обозначение | Значение |
| -------- | ----------- | :------: |
| Входы | $x_1,\ x_2$ | 0,4; 0,6 |
| Начальные веса | $w_1,\ w_2$ | 0,2; 0,3 |
| Смещение | $b$ | −0,1 |
| Целевое значение | $y$ | 1 |
| Скорость обучения | $\eta$ | 0,1 |

Нужно выполнить 3 итерации градиентного спуска (вариант №3).

## Алгоритм по шагам

Одна итерация обучения состоит из четырёх этапов.

### 1. Прямое распространение (forward pass)

Нейрон считает взвешенную сумму входов и пропускает её через функцию активации — сигмоиду:

$$z=w_1x_1+w_2x_2+b,\qquad a=\sigma(z)=\frac{1}{1+e^{-z}}$$

Сигмоида переводит любое число в интервал $(0;1)$, поэтому выход $a$ можно трактовать как «степень уверенности» нейрона.

### 2. Вычисление ошибки

Ошибка — половина квадрата отклонения выхода от цели:

$$L=\frac{(a-y)^2}{2}$$

Множитель $\tfrac12$ удобен тем, что сокращает двойку при дифференцировании.

### 3. Обратное распространение (backward pass)

Нужно найти $\dfrac{\partial L}{\partial w_i}$ и $\dfrac{\partial L}{\partial b}$. Ошибка зависит от весов через цепочку $w \to z \to a \to L$, поэтому по правилу цепочки:

$$\frac{\partial L}{\partial w_i}=\frac{\partial L}{\partial a}\cdot\frac{\partial a}{\partial z}\cdot\frac{\partial z}{\partial w_i}$$

Каждый множитель считается отдельно:

| Звено цепочки | Формула | Откуда берётся |
| ------------- | ------- | -------------- |
| $\dfrac{\partial L}{\partial a}$ | $a-y$ | Производная $\tfrac12(a-y)^2$ |
| $\dfrac{\partial a}{\partial z}$ | $a(1-a)$ | Производная сигмоиды: $\sigma'(z)=\sigma(z)\bigl(1-\sigma(z)\bigr)$ |
| $\dfrac{\partial z}{\partial w_i}$ | $x_i$ | $z$ линейно зависит от $w_i$ |
| $\dfrac{\partial z}{\partial b}$ | $1$ | $b$ входит в $z$ с коэффициентом 1 |

Произведение первых двух множителей — **дельта нейрона**, общая часть всех градиентов:

$$\delta=\frac{\partial L}{\partial z}=(a-y)\cdot a(1-a)$$

Тогда градиенты получаются умножением дельты на вход:

$$\frac{\partial L}{\partial w_1}=\delta\,x_1,\qquad \frac{\partial L}{\partial w_2}=\delta\,x_2,\qquad \frac{\partial L}{\partial b}=\delta$$

Практический смысл: чем больше вход $x_i$, тем сильнее соответствующий вес влияет на ошибку и тем сильнее он корректируется.

### 4. Обновление весов

Каждый параметр сдвигается против градиента на величину, пропорциональную скорости обучения $\eta$:

$$w^{new}=w^{old}-\eta\,\frac{\partial L}{\partial w}$$

После этого этапы 1–4 повторяются с новыми весами. Если $\eta$ выбрано разумно, ошибка с каждой итерацией убывает.

## Пример: первая итерация

1. **Прямой проход.** $z=0{,}2\cdot0{,}4+0{,}3\cdot0{,}6-0{,}1=0{,}16$, $a=\sigma(0{,}16)\approx0{,}540$.
2. **Ошибка.** $L=\dfrac{(0{,}540-1)^2}{2}\approx0{,}1058$.
3. **Обратный проход.**
   $\dfrac{\partial L}{\partial a}\approx-0{,}460$, $\dfrac{\partial a}{\partial z}\approx0{,}248$, $\delta\approx-0{,}114$.
   $\dfrac{\partial L}{\partial w_1}\approx-0{,}0457$, $\dfrac{\partial L}{\partial w_2}\approx-0{,}0686$, $\dfrac{\partial L}{\partial b}\approx-0{,}114$.
4. **Обновление.**
   $w_1=0{,}2-0{,}1\cdot(-0{,}0457)\approx0{,}2046$,
   $w_2=0{,}3-0{,}1\cdot(-0{,}0686)\approx0{,}3069$,
   $b=-0{,}1-0{,}1\cdot(-0{,}114)\approx-0{,}0886$.

Все градиенты отрицательные, значит, веса и смещение **увеличиваются**, выход $a$ приближается к целевой единице.

## Программа

| Функция | Что делает |
| ------- | ---------- |
| `sigmoid` | Сигмоида $\sigma(x)=\dfrac{1}{1+e^{-x}}$ |
| `forward_pass` | Прямое распространение: возвращает $z$ и $a$ |
| `compute_loss` | Считает ошибку $L=\tfrac12(a-y)^2$ |
| `backward_pass` | Обратное распространение: возвращает $\dfrac{\partial L}{\partial w_1}$, $\dfrac{\partial L}{\partial w_2}$, $\dfrac{\partial L}{\partial b}$ и дельту $\delta$ |
| `update_weights` | Один шаг градиентного спуска для $w_1$, $w_2$, $b$ |

Основной цикл выполняет 3 итерации: прямой проход → ошибка → обратный проход → обновление весов → контрольный прямой проход с новыми весами.

## Результаты

Значения по итерациям ($L$ — ошибка до обновления весов, последний столбец — ошибка при контрольном проходе после обновления):

| Итерация | $z$ | $a$ | $L$ | $\delta$ | $w_1$ | $w_2$ | $b$ | $L$ после обновления |
| :------: | :-: | :-: | :-: | :------: | :---: | :---: | :-: | :------------------: |
| 1 | 0,1600 | 0,5399 | 0,105839 | −0,1143 | 0,2046 | 0,3069 | −0,0886 | 0,103864 |
| 2 | 0,1774 | 0,5442 | 0,103864 | −0,1131 | 0,2091 | 0,3136 | −0,0773 | 0,101932 |
| 3 | 0,1946 | 0,5485 | 0,101932 | −0,1118 | 0,2136 | 0,3203 | −0,0661 | 0,100042 |

**Итог после 3 итераций:**

- веса и смещение: $w_1\approx0{,}2136$, $w_2\approx0{,}3203$, $b\approx-0{,}0661$;
- выход сети: $a\approx0{,}5527$;
- ошибка: $L\approx0{,}1000$ (было $0{,}1058$).

**Вывод.** Ошибка монотонно уменьшается с каждой итерацией, а выход нейрона медленно приближается к целевому значению 1. Скорость сходимости невелика: шаг градиентного спуска пропорционален $\delta$, а при $a\approx0{,}5$ производная сигмоиды $a(1-a)\approx0{,}25$ даёт небольшие поправки. Для заметного приближения к цели нужно больше итераций либо большее $\eta$.

## Ограничения

- Рассмотрен один нейрон. В многослойной сети дельты слоёв вычисляются последовательно от выхода ко входу: дельта скрытого слоя выражается через дельты следующего слоя и его веса.
- Сигмоида насыщается: при больших $|z|$ её производная $a(1-a)$ близка к нулю, и градиенты затухают. В глубоких сетях это приводит к проблеме затухающего градиента, поэтому там чаще используют ReLU и аналогичные функции.
- Результат зависит от скорости обучения $\eta$: при слишком большом значении ошибка может расти, при слишком малом обучение идёт очень медленно.
