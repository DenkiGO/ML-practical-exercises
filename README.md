## Метод K ближайших соседей

**Идея.** Класс нового объекта определяется классами его $K$ ближайших соседей из обучающей выборки: побеждает класс, который среди соседей встречается чаще всего. Модель не обучается заранее, вся работа происходит в момент классификации.

**Алгоритм.**

1. Вычислить расстояние от нового объекта до каждого объекта обучающей выборки.
2. Отсортировать объекты по возрастанию расстояния и выбрать $K$ ближайших.
3. Подсчитать, сколько соседей относится к каждому классу.
4. Присвоить объекту класс, набравший больше всего голосов.

**Метрики расстояния.** Для объектов с $n$ признаками чаще всего применяют две метрики.

Евклидово расстояние:

```math
d(x,y)=\sqrt{\sum_{k=1}^{n}(x_k-y_k)^2}
```

Манхэттенское расстояние (сумма модулей разностей):

```math
d(x,y)=\sum_{k=1}^{n}\lvert x_k-y_k\rvert
```

**Параметры.** Число соседей $K$ и метрика. При малом $K$ результат чувствителен к выбросам, при большом в голосование попадают объекты чужих классов. Признаки перед расчётом нормализуют, иначе признак с большим диапазоном будет доминировать.

**Ограничения.** Все соседи голосуют одинаково, независимо от расстояния; результат — одна метка без оценки уверенности; при равенстве голосов нужно дополнительное правило. Эти недостатки устраняет [Fuzzy K-NN](#fuzzy-k-nn).

## Наивный байесовский классификатор

**Идея.** Для объекта вычисляется вероятность каждого класса по теореме Байеса, а выбирается класс с наибольшей вероятностью. «Наивность» — в допущении, что признаки независимы друг от друга при известном классе. Типичное применение — фильтр спама, где признаками служат слова письма.

**Алгоритм.**

1. По обучающей выборке оценить априорную вероятность каждого класса: долю писем класса среди всех писем.
2. Для каждого признака (слова) оценить условную вероятность его появления в каждом классе.
3. Для нового письма перемножить вероятности его слов в каждом классе и умножить на априорную вероятность класса.
4. Выбрать класс с наибольшим результатом.

```math
P(c\mid x_1,\dots,x_n)\ \propto\ P(c)\cdot\prod_{k=1}^{n}P(x_k\mid c)
```

**Практические детали.**

- Если слово не встречалось в обучающих письмах класса, его вероятность равна нулю и обнуляет всё произведение. Чтобы избежать этого, применяют сглаживание (например, Лапласа): ко всем счётчикам слов добавляют малую константу.
- Произведение многих малых вероятностей быстро приближается к нулю, поэтому на практике вычисляют сумму логарифмов вероятностей.

**Ограничения.** Допущение о независимости слов почти никогда не выполняется строго, но на практике метод даёт хорошие результаты и очень быстро обучается.

## Метод опорных векторов

**Идея.** Метод ищет гиперплоскость, которая разделяет два класса так, чтобы расстояние (зазор) до ближайших объектов обеих групп было максимальным. Объекты, лежащие на границе зазора, называют **опорными векторами**: только они определяют положение гиперплоскости, остальные объекты на неё не влияют.

**Решающее правило.** Гиперплоскость задаётся вектором весов $w$ и смещением $b$. Класс нового объекта $x$ определяется знаком линейной функции:

```math
f(x)=w\cdot x+b,\qquad \hat{y}=\mathrm{sign}\bigl(f(x)\bigr)
```

**Максимизация зазора.** Ширина зазора равна $2/\lVert w\rVert$, поэтому максимизация зазора равносильна минимизации $\lVert w\rVert$ при условии, что все объекты классифицированы правильно:

```math
\min_{w,b}\ \frac12\lVert w\rVert^2\quad\text{при}\quad y_i\,(w\cdot x_i+b)\ge1
```

**Алгоритм.**

1. Задать обучающую выборку с метками классов $y_i\in\{-1,+1\}$.
2. Найти $w$ и $b$, решая задачу оптимизации выше.
3. Определить опорные векторы — объекты, для которых $y_i\,(w\cdot x_i+b)=1$.
4. Классифицировать новые объекты по знаку $f(x)$.

**Расширения.** Если классы нельзя разделить без ошибок, вводят «мягкий зазор» с штрафом за нарушения. Если граница нелинейна, применяют ядра, которые неявно переводят данные в пространство большей размерности.

## Обучение сверточного слоя

**Идея.** Сверточный слой использует небольшое ядро, которое скользит по входной матрице и в каждой позиции вычисляет взвешенную сумму. Одни и те же веса применяются ко всем позициям, поэтому параметров мало, а признак находится в любом месте изображения. Обучение подбирает веса ядра и смещение методом обратного распространения ошибки.

**Прямой проход.** Свертка входа $X$ с ядром $W$, добавление смещения $b$ и активация ReLU:

```math
Z_{i,j}=\sum_{m,n}X_{i+m,\,j+n}\,W_{m,n}+b,\qquad a_{i,j}=\max(0,\,Z_{i,j})
```

**Функция потерь.** Среднеквадратичная ошибка:

```math
L=\frac12\sum_{i,j}\bigl(a_{i,j}-y_{i,j}\bigr)^2
```

**Обратный проход.** Градиенты находятся по правилу цепочки от выхода к параметрам:

1. Градиент по выходу: $\partial L/\partial a=a-y$.
2. Градиент через ReLU: умножение на 1 там, где $z>0$, и на 0 в остальных местах.
3. Градиент по смещению: сумма градиентов по всем позициям.
4. Градиент по весам ядра: свертка входа с матрицей $\partial L/\partial z$.

**Обновление параметров.** Градиентный спуск со скоростью обучения $\alpha$:

```math
W^{new}=W^{old}-\alpha\,\frac{\partial L}{\partial W},\qquad b^{new}=b^{old}-\alpha\,\frac{\partial L}{\partial b}
```

**Что показывает работа.** При слишком большом $\alpha$ шаги перепрыгивают минимум, ошибка растёт, а ReLU может обнулить весь выход: градиент становится нулевым, и обучение останавливается («умирание ReLU»). При меньшем $\alpha$ ошибка убывает монотонно, но медленнее.

## Нечёткие множества

**Идея.** В обычном множестве элемент либо принадлежит множеству, либо нет. В нечётком множестве каждому элементу сопоставлена **степень принадлежности** $\mu(x)\in[0;1]$: чем ближе к 1, тем сильнее элемент соответствует понятию. Так записываются расплывчатые понятия вроде «комфортная температура» или «высокая нагрузка».

| Понятие | Формула | Смысл |
| ------- | :-----: | ----- |
| Носитель | $\{x\mid\mu(x)>0\}$ | Элементы, принадлежащие множеству хотя бы в какой-то степени |
| Высота | $h=\max\limits_x\mu(x)$ | Наибольшая степень принадлежности |
| Нормализация | $\mu_N(x)=\mu(x)/h$ | Приведение множества к высоте 1 |

**Функции принадлежности.** Для задания нечётких понятий используют стандартные виды: L-образную (убывающую), треугольную и гамма-образную (возрастающую). Они кусочно-линейны и определяются двумя-тремя параметрами.

## Fuzzy K-NN

**Идея.** Расширение [метода K ближайших соседей](#метод-k-ближайших-соседей): соседи голосуют с весами, убывающими с расстоянием, а результатом служит вектор степеней принадлежности объекта ко всем классам, сумма которых равна 1. Так метод оценивает уверенность решения и разрешает ничью весами.

**Алгоритм.**

1. Найти $K$ ближайших соседей объекта $x$.
2. Для каждого соседа вычислить вес:

```math
w_i=\frac{1}{d(x,x_i)^{\frac{2}{m-1}}+\varepsilon}
```

   где $m>1$ — параметр нечёткости (обычно 2), $\varepsilon$ — малая константа для защиты от деления на ноль.

3. Для каждого класса $j$ вычислить степень принадлежности как взвешенное среднее степеней принадлежности соседей:

```math
u_j(x)=\frac{\sum\limits_{i=1}^{K}u_{ij}\,w_i}{\sum\limits_{i=1}^{K}w_i}
```

4. Отнести объект к классу с наибольшей степенью принадлежности. Само значение показывает уверенность.

**Параметры.** С ростом $m$ веса соседей выравниваются, и метод приближается к обычному голосованию; чем меньше $m$, тем сильнее влияние самых близких соседей. Обучающие объекты могут иметь чёткие метки или нечёткие, которые строятся, например, методом Келлера.

## Fuzzy C-Means

**Идея.** Нечёткая кластеризация без учителя: каждая точка принадлежит каждому из $c$ кластеров со своей степенью $u_{ij}$, причём сумма степеней для точки равна 1. В отличие от жёсткого K-Means, пограничные точки делят принадлежность между кластерами.

**Целевая функция.** Алгоритм минимизирует взвешенную сумму квадратов расстояний от точек до центров кластеров:

```math
J=\sum_{i=1}^{n}\sum_{j=1}^{c}u_{ij}^{m}\,\lvert x_i-c_j\rvert^2
```

**Алгоритм.**

1. Задать начальную матрицу принадлежностей $U$ (сумма в каждой строке равна 1).
2. Вычислить центры кластеров как среднее точек, взвешенное степенями $u_{ij}^m$:

```math
c_j=\frac{\sum\limits_{i=1}^{n}u_{ij}^{m}\,x_i}{\sum\limits_{i=1}^{n}u_{ij}^{m}}
```

3. Вычислить расстояния от точек до центров.
4. Обновить матрицу принадлежностей: чем ближе точка к центру, тем больше её принадлежность этому кластеру:

```math
u_{ij}=\frac{1}{\sum\limits_{k=1}^{c}\left(\dfrac{d_{ij}}{d_{ik}}\right)^{\frac{2}{m-1}}}
```

5. Если наибольшее изменение элементов $U$ меньше порога $\varepsilon$, остановиться. Иначе вернуться к шагу 2.

Для жёсткого разбиения каждую точку относят к кластеру с наибольшей степенью принадлежности.

## Нечёткие отношения и их композиция

**Идея.** Нечёткое отношение между множествами $U$ и $V$ задаётся матрицей степеней связи $\mu(u,v)\in[0;1]$. Над отношениями определены поэлементные операции: пересечение (минимум), объединение (максимум), дополнение ($1-\mu$) и обратное отношение (транспонирование матрицы).

**Композиция.** Если даны отношения $R_1\subseteq U\times Z$ и $R_2\subseteq Z\times V$, их композиция описывает связь между $U$ и $V$ через промежуточный элемент $z$. Вычисляется она как матричное произведение, в котором операции «умножить и сложить» заменены другими.

| Вид | Формула для элемента $(u,v)$ |
| --- | :--------------------------: |
| Max-min | $\max\limits_{z}\min(\mu_{R_1}(u,z),\ \mu_{R_2}(z,v))$ |
| Min-max | $\min\limits_{z}\max(\mu_{R_1}(u,z),\ \mu_{R_2}(z,v))$ |
| Max-product | $\max\limits_{z}\ \mu_{R_1}(u,z)\cdot\mu_{R_2}(z,v)$ |
| Max-avg(min, prod) | $\max\limits_{z}$ полусуммы $\min$ и произведения |

**Алгоритм.**

1. Проверить размеры: $(n\times p)\circ(p\times m)$ даёт матрицу $n\times m$.
2. Для каждой пары (строка $i$, столбец $k$) и каждого промежуточного $j=1,\dots,p$ вычислить оценку цепочки по выбранному правилу.
3. Выбрать из $p$ оценок максимум или минимум (в зависимости от вида композиции).
4. Записать значение в элемент результата.

Композиция не коммутативна: $R_1\circ R_2$ в общем случае не равно $R_2\circ R_1$.

## Муравьиный алгоритм

**Идея.** Метаэвристика для комбинаторной оптимизации, вдохновлённая поведением муравьёв. Муравьи оставляют на пройденных рёбрах феромон, а другие предпочитают рёбра с большим количеством феромона; на коротких путях он накапливается быстрее, а со временем испаряется, поэтому плохие маршруты забываются. В задаче коммивояжёра ищется кратчайший замкнутый маршрут через все города.

**Алгоритм (одна итерация).**

1. На всех рёбрах задаётся начальный феромон $\tau_0$.
2. Каждый муравей строит маршрут, на каждом шаге выбирая следующий непосещённый город $j$ из текущего $i$ с вероятностью:

```math
P_{ij}=\frac{\tau_{ij}^{\alpha}\cdot\eta_{ij}^{\beta}}{\sum\limits_{l}\tau_{il}^{\alpha}\cdot\eta_{il}^{\beta}},\qquad \eta_{ij}=\frac{1}{L_{ij}}
```

3. Вычисляется длина каждого маршрута.
4. Феромон обновляется: испарение и откладывание добавки, которая тем больше, чем короче маршрут:

```math
\tau_{ij}^{new}=(1-\rho)\,\tau_{ij}^{old}+\sum\frac{Q}{L_k}
```

Итерации повторяют заданное число раз, лучшим решением считается самый короткий найденный маршрут. В отличие от полного перебора метод не гарантирует оптимум, зато применим к графам, где перебор невозможен.

## Общие понятия

| Понятие | Где используется | Пояснение |
| ------- | ---------------- | --------- |
| Нормализация признаков | K-NN, Fuzzy K-NN, Fuzzy C-Means | Приведение признаков к одному масштабу, например на отрезок $[0;1]$, чтобы ни один не доминировал в расстоянии |
| Расстояние | K-NN, Fuzzy K-NN, Fuzzy C-Means | Мера близости объектов: евклидово или манхэттенское |
| Параметр нечёткости $m$ | Fuzzy K-NN, Fuzzy C-Means | Определяет, насколько «размыта» принадлежность; обычно $m=2$ |
| Степень принадлежности | Вся нечёткая логика | Число из $[0;1]$, показывающее, насколько объект относится к классу или кластеру |
| Градиентный спуск | Сверточный слой | Изменение параметров в сторону, противоположную градиенту ошибки |
| Скорость обучения | Сверточный слой | Размер шага градиентного спуска |

## Как устроено описание алгоритма в README

Все README построены по одной структуре:

1. **Цель** — что нужно изучить.
2. **Теория** — идея метода и необходимые определения.
3. **Алгоритм** — шаги с формулами и псевдокод.
4. **Задача и данные** — исходные числа для расчёта.
5. **Ручной расчёт** — пошаговое решение с промежуточными значениями.
6. **Программа** — таблица функций и вывод.
7. **Запуск** — команда для запуска.
8. **Выводы и технологии**.

Результат программы всегда сверяется с ручным расчётом, поэтому каждый README можно использовать как проверочный пример к скрипту.

## Запуск

Скрипты запускаются командой `python <файл>.py`. Для работ с матричными вычислениями нужен NumPy:

```bash
pip install numpy
```

Часть работ (например, Fuzzy K-NN и обучение сверточного слоя) написана на чистом Python и сторонних библиотек не требует. Для построения графиков функций принадлежности дополнительно нужен `matplotlib`.
