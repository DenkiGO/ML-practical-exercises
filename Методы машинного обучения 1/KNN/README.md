## Метод KNN

**KNN (k nearest neighbors, метод k ближайших соседей)** — простой алгоритм классификации, основанный на идее «похожие объекты имеют одинаковый класс». Отдельного этапа обучения у него нет: алгоритм просто хранит выборку с известными классами.

Чтобы определить класс нового объекта, алгоритм:

1. вычисляет расстояние от нового объекта до каждого объекта выборки (по выбранной метрике);
2. выбирает `k` ближайших объектов, то есть его «соседей»;
3. присваивает новому объекту класс, который чаще всего встречается среди соседей (при `k = 1` берётся класс единственного ближайшего соседа).

Результат зависит от двух параметров: числа соседей `k` и метрики расстояния. Если признаки измерены в разных масштабах, их обычно нормируют, чтобы один признак не доминировал над остальными. В этой работе признаки имеют сопоставимый диапазон, поэтому нормировка не применялась.

## Задача

Оценить качество защищённого Wi-Fi канала по трём признакам:

| Признак | Что отражает |
| ------- | ------------ |
| Уровень сигнала, dBm | Мощность полезного сигнала |
| Уровень шума, dBm | Мощность фоновых помех |
| Потеря пакетов, % | Целостность передачи данных |

Класс объекта: `1` — хорошее качество, `0` — плохое. Обучающая выборка состоит из 10 объектов. Нужно определить класс нового объекта №11 с признаками `(60, 85, 20)`.

## Метрики расстояния

| Метрика | Формула | Особенность |
| ------- | ------- | ----------- |
| Манхэттенская | $d(p,q)=\sum_i \lvert p_i-q_i\rvert$ | Меньше реагирует на выбросы, чем евклидова |
| Евклидова | $d(p,q)=\sqrt{\sum_i (p_i-q_i)^2}$ | Обычное геометрическое расстояние |
| Чебышева | $d(p,q)=\max_i \lvert p_i-q_i\rvert$ | Объекты различны, если отличаются хотя бы по одному признаку |

## Как работает программа

Для каждой метрики в `lab_1.py` есть функция (`function_manheton`, `function_evklida`, `function_chepusheva`), которая:

1. считает расстояние от тестового объекта до каждого объекта выборки;
2. ранжирует объекты: ранг 1 у ближайшего;
3. возвращает расстояния и ранги.

Класс тестового объекта берётся у ближайшего соседа, а результат выводится таблицей (`tabulate`).

Пример для соседа №10, объект `(60, 93, 8)` и тестовый `(60, 85, 20)`:

- Манхэттен: `|60−60| + |85−93| + |20−8| = 20`
- Евклид: `√(0 + 64 + 144) ≈ 14,42`
- Чебышев: `max{0, 8, 12} = 12`

Расстояния от объекта №11 до объектов выборки (в скобках ранг):

| № | Класс | Манхэттен | Евклид | Чебышев |
| - | :---: | :-------: | :----: | :-----: |
| 1 | 1 | 55 (10) | 33,54 (9) | 25 (8) |
| 2 | 1 | 40 (8) | 24,45 (7) | 18 (5) |
| 3 | 1 | 25 (3) | 16,58 (3) | 15 (2) |
| 4 | 0 | 23 (2) | 16,09 (2) | 15 (3) |
| 5 | 1 | 37 (6) | 23,56 (6) | 19 (6) |
| 6 | 0 | 30 (4) | 25,50 (8) | 25 (9) |
| 7 | 0 | 36 (5) | 23,15 (5) | 20 (7) |

**Вывод.** По всем трём метрикам ближайший сосед — объект №10 с классом **0**, поэтому объект №11 относится к классу **0 (плохое качество сигнала)**. Порядок остальных соседей зависит от метрики (второй по близости: №4 у Манхэттена и Евклида, №3 у Чебышева), но ближайший сосед везде один и тот же.
