## Нечёткие отношения

### Идея

**Нечёткое отношение** `R` между множествами `U` и `V` — нечёткое множество, заданное на декартовом произведении `U × V`:

```text
R = { ((u, v), μ_R(u, v)) | u ∈ U, v ∈ V }
```

Степень принадлежности `μ_R(u, v) ∈ [0, 1]` показывает, насколько сильно связаны объекты `u` и `v`: 1 означает полную связь, 0 — полное отсутствие связи, промежуточные значения — частичную связь. В чётком отношении пара либо связана, либо нет, а в нечётком связь можно оценить градацией.

Для конечных множеств отношение записывается **матрицей** `M_R = ‖μ_ij‖`, где `μ_ij = μ_R(u_i, v_j)`: строки соответствуют элементам `U`, столбцы — элементам `V`. Если `U = V`, отношение называют бинарным отношением на множестве `U`, и его матрица квадратная.

### Поэлементные операции

Они определяются через операции над нечёткими множествами и применяются к каждому элементу матрицы отдельно. Для пересечения и объединения матрицы должны быть одного размера.

| Операция | Формула | Смысл |
| -------- | :-----: | ----- |
| Пересечение `R₁ ∩ R₂` | `min(μ_R₁(u,v), μ_R₂(u,v))` | Пара связана настолько, насколько она связана в обоих отношениях |
| Объединение `R₁ ∪ R₂` | `max(μ_R₁(u,v), μ_R₂(u,v))` | Пара связана настолько, насколько она связана хотя бы в одном отношении |
| Дополнение `R̄` | `1 − μ_R(u,v)` | Степень «отсутствия» связи |
| Обратное `R⁻¹` | `μ_R⁻¹(v,u) = μ_R(u,v)` | Те же связи, но в обратном направлении (транспонирование матрицы) |

## Композиция нечётких отношений

### Идея

Пусть известны два отношения: `R₁ ⊆ U × Z` и `R₂ ⊆ Z × V`. Нужно найти отношение между `U` и `V`, если связь идёт **через промежуточный элемент** `z ∈ Z`:

```text
R₁ ∘ R₂ ⊆ U × V
```

Пара `(u, v)` связана тем сильнее, чем лучше найдётся хотя бы один «мост» `z`, такой что `u` связан с `z`, а `z` связан с `v`. Для каждого `z` связь по цепочке `u → z → v` оценивается через степени `μ_R₁(u, z)` и `μ_R₂(z, v)`, а затем из всех мостов выбирается лучший (или самый осторожный, для min-max).

### Связь с произведением матриц

Композиция устроена так же, как обычное умножение матриц, но вместо пары операций «умножить и сложить» используются другие операции:

```text
обычное произведение:  c_ik = Σ_j a_ij · b_jk
композиция:            c_ik = агрегация_j ( a_ij «и» b_jk )
```

Операция «и» объединяет два звена цепочки, а агрегация выбирает среди всех промежуточных `j`. Разные пары операций дают разные виды композиции.

### Виды композиции

| Вид | Формула `μ_R₁∘R₂(u, v)` | «Звено цепочки» | Агрегация по `z` |
| --- | :---------------------: | :-------------: | :--------------: |
| Max-min | `max_z min(μ_R₁(u,z), μ_R₂(z,v))` | `min` | `max` |
| Min-max | `min_z max(μ_R₁(u,z), μ_R₂(z,v))` | `max` | `min` |
| Max-product | `max_z μ_R₁(u,z) · μ_R₂(z,v)` | произведение | `max` |
| Max-avg(min, prod) | `max_z [min(μ_R₁(u,z), μ_R₂(z,v)) + μ_R₁(u,z)·μ_R₂(z,v)] / 2` | полусумма min и произведения | `max` |

В случае бесконечных множеств максимум и минимум заменяются на `sup` и `inf`.

Как читать каждый вид:

- **Max-min** — самая распространённая композиция. Цепочка не крепче самого слабого звена (min), а из всех цепочек выбирается самая крепкая (max).
- **Min-max** — «двойственная» композиция: цепочка оценивается по самому сильному звену (max), а среди всех цепочек выбирается наименьшая оценка (min). Результат тем меньше, чем лучше существует «мост» с малыми значениями.
- **Max-product** — произведение степеней: слабые звенья снижают оценку цепочки сильнее, чем при min, но результат остаётся в `[0, 1]`.
- **Max-avg(min, prod)** — смешанная композиция: оценка звена берётся как среднее между min и произведением, то есть находится между этими двумя крайностями.

### Алгоритм вычисления композиции

**Шаг 1. Проверка размеров.** Для `A` размером `n × p` и `B` размером `p × m` композиция определена: число столбцов `A` должно быть равно числу строк `B`. Результат имеет размер `n × m`.

**Шаг 2. Выбор элемента.** Для каждой пары `(i, k)` — строка `i` матрицы `A` и столбец `k` матрицы `B` — вычисляется один элемент результата.

**Шаг 3. Оценка цепочек.** Для каждого промежуточного элемента `j = 1, …, p` берётся пара `a_ij` и `b_jk` и по выбранному правилу «и» вычисляется оценка цепочки (min, max, произведение или полусумма min и произведения).

**Шаг 4. Агрегация.** Из `p` оценок выбирается итоговая: максимум или минимум в зависимости от вида композиции.

**Шаг 5. Запись результата.** Значение записывается в элемент `c_ik`. После обхода всех пар `(i, k)` матрица результата готова.

### Псевдокод

```text
n ← число строк A, p ← число столбцов A (= число строк B), m ← число столбцов B
для i от 1 до n:
    для k от 1 до m:
        для j от 1 до p:
            t[j] ← «и»(A[i][j], B[j][k])     # min, max, произведение или (min + произведение)/2
        C[i][k] ← агрегация(t[1..p])         # max для max-min, max-product, max-avg; min для min-max
вернуть C
```

Сложность: `O(n · m · p)`, как у обычного матричного умножения.

### Пример вычисления одного элемента

Элемент `(1, 1)`: строка 1 матрицы `R₁` равна `(0,8; 0,3; 0,5)`, столбец 1 матрицы `R₂` равен `(0,5; 0,6; 0,3)`.

| Вид | Оценки цепочек по `j = 1, 2, 3` | Результат |
| --- | :---------------------------: | :-------: |
| Max-min | `min`: 0,5; 0,3; 0,3 | `max = 0,5` |
| Min-max | `max`: 0,8; 0,6; 0,5 | `min = 0,5` |
| Max-product | 0,4; 0,18; 0,15 | `max = 0,4` |
| Max-avg(min, prod) | (0,5 + 0,4)/2 = 0,45; (0,3 + 0,18)/2 = 0,24; (0,3 + 0,15)/2 = 0,225 | `max = 0,45` |

### Свойства

- **Размеры.** Композиция `(n × p) ∘ (p × m)` даёт матрицу `n × m`, все значения остаются в `[0, 1]`.
- **Не коммутативна.** `R₁ ∘ R₂ ≠ R₂ ∘ R₁` в общем случае. Для данных работы по max-min: элемент `(2, 3)` равен 0,8 у `R₁ ∘ R₂` и 0,7 у `R₂ ∘ R₁`.
- **Ассоциативность.** Для max-min композиции `(R₁ ∘ R₂) ∘ R₃ = R₁ ∘ (R₂ ∘ R₃)`.

## Задание 1. Композиция отношений

**Данные:**

```text

         ⎛ 0,8  0,3  0,5 ⎞            ⎛ 0,5  0,7  0,2 ⎞
R₁ =     ⎜ 0,4  0,9  0,2 ⎟ ,   R₂ =   ⎜ 0,6  0,4  0,8 ⎟
         ⎝ 0,6  0,1  0,7 ⎠            ⎝ 0,3  0,9  0,5 ⎠
```

**Max-min:**

```text

            ⎛ 0,5  0,7  0,5 ⎞
R₁ ∘ R₂ =   ⎜ 0,6  0,4  0,8 ⎟
            ⎝ 0,5  0,7  0,5 ⎠
```

Например, элемент `(1, 2)` равен `max(min(0,8; 0,7), min(0,3; 0,4), min(0,5; 0,9)) = max(0,7; 0,3; 0,5) = 0,7`.

**Min-max:**

```text

            ⎛ 0,5  0,4  0,5 ⎞
R₁ ∘ R₂ =   ⎜ 0,3  0,7  0,4 ⎟
            ⎝ 0,6  0,4  0,6 ⎠
```

Например, элемент `(1, 2)` равен `min(max(0,8; 0,7), max(0,3; 0,4), max(0,5; 0,9)) = min(0,8; 0,4; 0,9) = 0,4`.

**Max-product:**

```text

            ⎛ 0,4   0,56  0,25 ⎞
R₁ ∘ R₂ =   ⎜ 0,54  0,36  0,72 ⎟
            ⎝ 0,3   0,63  0,35 ⎠
```

Например, элемент `(2, 3)` равен `max(0,4·0,2; 0,9·0,8; 0,2·0,5) = max(0,08; 0,72; 0,1) = 0,72`.

**Max-avg(min, prod):**

```text

            ⎛ 0,45  0,63   0,375 ⎞
R₁ ∘ R₂ =   ⎜ 0,57  0,38   0,76  ⎟
            ⎝ 0,4   0,665  0,425 ⎠
```

### Сравнение результатов

Композиции дают разные оценки одних и тех же связей:

| Вид | Диапазон значений | Особенность |
| --- | :---------------: | ----------- |
| Max-min | 0,4 – 0,8 | Значения всегда совпадают с элементами исходных матриц |
| Min-max | 0,3 – 0,7 | Тоже берёт значения исходных матриц, но по «самому сильному» звену |
| Max-product | 0,25 – 0,72 | Новые значения: произведения снижают оценки |
| Max-avg(min, prod) | 0,375 – 0,76 | Значения лежат между max-min и max-product |

Для max-min и min-max результат состоит только из чисел, которые уже есть в исходных матрицах, а для max-product и max-avg появляются новые значения.

## Программа

| Функция | Что делает |
| ------- | ---------- |
| `max_min(A, B)` | Max-min композиция |
| `min_max(A, B)` | Min-max композиция |
| `max_product(A, B)` | Max-product композиция |
| `max_avg_min_prod(A, B)` | Композиция max-avg: максимум полусуммы `min(a,b)` и `a·b` |
| `intersection(A, B)` | Пересечение: `np.minimum(A, B)` |
| `union(A, B)` | Объединение: `np.maximum(A, B)` |
| `complement(A)` | Дополнение: `1 - A` |
| `inverse(A)` | Обратное отношение: транспонирование `A.T` |

Все четыре функции композиции устроены одинаково: три вложенных цикла (строка `i`, столбец `k`, промежуточный индекс `j`), в которых для каждого `j` вычисляется оценка цепочки, а затем применяется `max` или `min`. Поэлементные операции реализованы средствами NumPy без циклов. Программа печатает результаты всех операций для заданных `R₁` и `R₂`.

## Выводы

В работе реализованы и проверены поэлементные операции над нечёткими отношениями (пересечение, объединение, дополнение, обратное отношение) и четыре вида композиции: max-min, min-max, max-product и max-avg.
