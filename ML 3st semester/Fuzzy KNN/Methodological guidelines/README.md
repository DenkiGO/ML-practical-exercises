## Теоретическая часть

### Классический K-NN и его ограничения

**K ближайших соседей (K-NN)** — метрический алгоритм классификации. Для нового объекта $x$ в обучающей выборке находятся $K$ ближайших объектов, и $x$ получает тот класс, который чаще всего встречается среди соседей (голосование по большинству). У метода есть недостатки:

- все $K$ соседей имеют одинаковый вес, независимо от того, находятся они рядом с объектом или у границы окрестности;
- результат — единственная метка класса, поэтому невозможно оценить уверенность решения;
- объекты на границе между классами классифицируются так же «жёстко», как типичные представители класса;
- при равенстве голосов нужно дополнительное правило.

**Fuzzy K-NN**, предложенный Дж. Келлером с соавторами в 1985 году, устраняет эти недостатки: каждый сосед голосует с весом, обратно пропорциональным расстоянию, а результатом является вектор степеней принадлежности ко всем классам.

### Степень принадлежности

Каждый объект $x$ характеризуется вектором степеней принадлежности к классам:

```math
u(x)=\bigl(u_1(x),\,u_2(x),\,\dots,\,u_C(x)\bigr),\qquad u_j(x)\in[0,1],\qquad \sum_{j=1}^{C}u_j(x)=1
```

где $C$ — число классов. Степень принадлежности не является вероятностью в строгом смысле: она отражает, насколько объект «похож» на типичных представителей класса. Вектор $(0{,}7;\ 0{,}3;\ 0{,}0)$ означает, что объект в основном относится к первому классу, частично ко второму и совсем не относится к третьему.

### Метрики расстояния

Близость объектов определяется расстоянием $d(x,x_i)$ в пространстве $n$ признаков.

Евклидово расстояние:

```math
d(x,x_i)=\sqrt{\sum_{k=1}^{n}\bigl(x_k-x_{i,k}\bigr)^2}
```

Манхэттенское расстояние (сумма модулей разностей):

```math
d(x,x_i)=\sum_{k=1}^{n}\bigl\lvert x_k-x_{i,k}\bigr\rvert
```

Признаки могут иметь разные единицы измерения, поэтому перед расчётом их приводят к единому масштабу, например min-max нормализацией на отрезок $[0;1]$:

```math
x'=\frac{x-x_{min}}{x_{max}-x_{min}}
```

Без нормализации признак с большим диапазоном значений будет доминировать при вычислении расстояния. Во всех примерах и заданиях пособия признаки уже нормированы.

### Веса соседей и параметр нечёткости

Каждому из $K$ найденных соседей присваивается вес, обратно пропорциональный расстоянию:

```math
w_i=\frac{1}{d(x,x_i)^{\frac{2}{m-1}}+\varepsilon}
```

где $m>1$ — параметр нечёткости (обычно $m=2$), $\varepsilon$ — малая константа (обычно $0{,}01$), которая исключает деление на ноль, если объект совпал с соседом.

Параметр $m$ определяет, насколько сильно вес соседа зависит от расстояния:

| $m$ | Показатель $\dfrac{2}{m-1}$ | Вес соседа |
| :-: | :-------------------------: | :--------: |
| 1,5 | 4 | $1/(d^4+\varepsilon)$ |
| 2 | 2 | $1/(d^2+\varepsilon)$ |
| 3 | 1 | $1/(d+\varepsilon)$ |

Чем меньше $m$, тем быстрее убывает вес с ростом расстояния и тем сильнее результат определяется самыми близкими соседями. С ростом $m$ веса выравниваются, и метод приближается к обычному голосованию по большинству.

### Степени принадлежности обучающих объектов

Для расчёта нужны степени принадлежности $u_{ij}$ каждого обучающего объекта $i$ к каждому классу $j$. Есть два способа их задать.

**Чёткие метки.** Объект принадлежит своему классу $c_i$ со степенью 1, остальным со степенью 0:

```math
u_{ij}=\begin{cases}1, & j=c_i\\ 0, & j\ne c_i\end{cases}
```

**Нечёткие метки.** Частичные принадлежности берутся как есть (от эксперта или из предыдущего расчёта, пример 3), либо строятся автоматически **по методу Келлера**. Для каждого обучающего объекта находятся его $K$ ближайших соседей (без самого объекта), и $n_j$ — число соседей класса $j$. Тогда:

```math
u_{ij}=\begin{cases}0{,}51+0{,}49\cdot\dfrac{n_j}{K}, & j=c_i\\ 0{,}49\cdot\dfrac{n_j}{K}, & j\ne c_i\end{cases}
```

Объект, окружённый «чужими» объектами, получает менее уверенную метку, чем типичный представитель класса. Например, для объекта A из примера 1 при $K=3$ соседями являются B и C (класс «Нормальное») и D (класс «Подозрительное»), то есть $n_1=2$, $n_2=1$, и $u_{A,1}=0{,}51+0{,}49\cdot\frac23\approx0{,}84$, $u_{A,2}=0{,}49\cdot\frac13\approx0{,}16$.

## Алгоритм Fuzzy K-NN

**Входные данные:** обучающая выборка со степенями принадлежности $u_{ij}$, классифицируемый объект $x$, число соседей $K$, параметр нечёткости $m$, константа $\varepsilon$, метрика расстояния.

### Шаги алгоритма

**Шаг 1. Поиск ближайших соседей.** Вычислить расстояния $d(x,x_i)$ от $x$ до всех объектов обучающей выборки, отсортировать по возрастанию и выбрать $K$ объектов с наименьшими расстояниями. Остальные объекты в дальнейшем расчёте не участвуют.

**Шаг 2. Веса соседей.** Для каждого из $K$ соседей вычислить вес:

```math
w_i=\frac{1}{d(x,x_i)^{\frac{2}{m-1}}+\varepsilon}
```

**Шаг 3. Степени принадлежности.** Для каждого класса $j$ вычислить взвешенное среднее степеней принадлежности соседей:

```math
u_j(x)=\frac{\sum\limits_{i=1}^{K}u_{ij}\cdot w_i}{\sum\limits_{i=1}^{K}w_i}
```

**Шаг 4. Решение.** Отнести объект к классу с наибольшей степенью принадлежности:

```math
c(x)=\arg\max_j\,u_j(x)
```

Значение $\max_j u_j(x)$ — это уверенность классификации: например, $0{,}9241$ означает уверенность $92{,}41\%$.

### Смысл шага 3

Степень принадлежности $u_j(x)$ — среднее степеней принадлежности соседей к классу $j$, взвешенное по расстоянию: чем ближе сосед, тем больше его вклад. Если сосед не относится к классу $j$, то $u_{ij}=0$, и его вес не входит в числитель, но входит в знаменатель. Именно это «разбавляет» уверенность в классе.

Сумма степеней принадлежности всегда равна 1, если у каждого обучающего объекта $\sum_j u_{ij}=1$:

```math
\sum_{j=1}^{C}u_j(x)=\frac{\sum_{i=1}^{K}w_i\sum_{j=1}^{C}u_{ij}}{\sum_{i=1}^{K}w_i}=\frac{\sum_{i=1}^{K}w_i}{\sum_{i=1}^{K}w_i}=1
```

Это свойство используется для **самопроверки расчёта**.

### Псевдокод

```text
для каждого объекта обучающей выборки i:
    d[i] ← расстояние(x, объект i)
взять K объектов с наименьшими d  →  соседи
для каждого соседа i:
    w[i] ← 1 / (d[i]^(2/(m−1)) + ε)
W ← сумма w[i] по соседям
для каждого класса j:
    u[j] ← (сумма u[i][j] · w[i] по соседям) / W
ответ ← класс с максимальным u[j];  уверенность = u[j]
```

### Выбор параметров

| Параметр | Рекомендация |
| :------: | ------------ |
| $K$ | Небольшое число (3–7), не больше размера обучающей выборки. При малом $K$ результат чувствителен к выбросам, при большом в расчёт попадают «чужие» классы |
| $m$ | Обычно от 1,5 до 3; $m=2$ — стандартное значение |
| $\varepsilon$ | Малое число (например, $0{,}01$): нужно только для защиты от деления на ноль |
| Признаки | Перед расчётом расстояний нормализовать |

Если две наибольшие степени принадлежности близки, объект считается **пограничным**, и его целесообразно передать на дополнительную проверку.

### Сравнение с классическим K-NN

| | Классический K-NN | Fuzzy K-NN |
| - | :---------------: | :--------: |
| Вклад соседей | Равный (голосование) | Зависит от расстояния |
| Результат | Один класс | Степени принадлежности ко всем классам |
| Оценка уверенности | Нет | Есть ($u_j$) |
| Равенство голосов | Требует правила разрешения | Разрешается весами |
| Метки обучающих объектов | Только чёткие | Чёткие или нечёткие |

## Примеры аналитического расчёта

Примеры расположены по возрастанию сложности. Промежуточные значения округляются до четырёх знаков после запятой. В каждом примере: нормированные признаки, $\varepsilon=0{,}01$.

### Пример 1. Классификация сетевого соединения

Два признака: $x_1$ — частота запросов, $x_2$ — доля неудачных попыток аутентификации. Два класса, чёткие метки, $K=3$, $m=2$.

| Объект | $x_1$ | $x_2$ | Класс |
| :----: | :---: | :---: | ----- |
| A | 0,20 | 0,20 | Нормальное |
| B | 0,40 | 0,30 | Нормальное |
| C | 0,30 | 0,50 | Нормальное |
| D | 0,70 | 0,60 | Подозрительное |
| E | 0,90 | 0,80 | Подозрительное |
| F | 0,80 | 0,50 | Подозрительное |

Классифицируемое соединение: $x=(0{,}50;\ 0{,}40)$.

**Шаг 1.** Расстояния, например до B: $\sqrt{(0{,}5-0{,}4)^2+(0{,}4-0{,}3)^2}=\sqrt{0{,}02}\approx0{,}1414$. Ближайшие соседи:

| Сосед | $d$ | Класс |
| :---: | :-: | ----- |
| B | 0,1414 | Нормальное |
| C | 0,2236 | Нормальное |
| D | 0,2828 | Подозрительное |

**Шаг 2.** Веса $w=1/(d^2+0{,}01)$:

| Сосед | $d^2$ | Вес |
| :---: | :---: | :-: |
| B | 0,02 | 33,3333 |
| C | 0,05 | 16,6667 |
| D | 0,08 | 11,1111 |
| **Сумма** | | **61,1111** |

**Шаг 3.** Нормальное: $(33{,}3333+16{,}6667)/61{,}1111=0{,}8182$. Подозрительное: $11{,}1111/61{,}1111=0{,}1818$. Проверка: $0{,}8182+0{,}1818=1$.

**Результат:** «Нормальное» с уверенностью **81,82 %**. Классический K-NN отдал бы классу «Нормальное» 2 голоса из 3 (66,67 %). Fuzzy K-NN учитывает, что два самых близких соседа (B и C) имеют наибольшие веса, но сохраняет ненулевую принадлежность классу «Подозрительное» из-за соседа D.

### Пример 2. Оценка уровня угрозы

Три признака: $x_1$ — интенсивность сетевой активности, $x_2$ — доля неудачных попыток входа, $x_3$ — интенсивность обращений к критичным ресурсам. Три класса, $K=5$, $m=2$, чёткие метки. Среди соседей оказываются объекты всех трёх классов.

| Объект | $x_1$ | $x_2$ | $x_3$ | Класс |
| :----: | :---: | :---: | :---: | ----- |
| A | 0,10 | 0,05 | 0,10 | Низкий |
| B | 0,20 | 0,15 | 0,20 | Низкий |
| C | 0,35 | 0,30 | 0,40 | Средний |
| D | 0,45 | 0,50 | 0,35 | Средний |
| E | 0,55 | 0,45 | 0,55 | Средний |
| F | 0,70 | 0,75 | 0,65 | Высокий |
| G | 0,90 | 0,85 | 0,95 | Высокий |
| H | 0,90 | 0,95 | 0,80 | Высокий |

Классифицируемое событие: $x=(0{,}50;\ 0{,}55;\ 0{,}50)$.

| Сосед | $d$ | Вес | Класс |
| :---: | :-: | :-: | ----- |
| E | 0,1225 | 40,0000 | Средний |
| D | 0,1658 | 26,6667 | Средний |
| C | 0,3082 | 9,5238 | Средний |
| F | 0,3202 | 8,8889 | Высокий |
| B | 0,5831 | 2,8571 | Низкий |
| **Сумма весов** | | **87,9365** | |

Степени принадлежности: «Низкий» $=2{,}8571/87{,}9365=0{,}0325$; «Средний» $=76{,}1905/87{,}9365=0{,}8664$; «Высокий» $=8{,}8889/87{,}9365=0{,}1011$. Сумма равна 1.

**Результат:** «Средний» с уверенностью **86,64 %**. Сосед B (класс «Низкий») вошёл в число пяти ближайших, но его вес составляет лишь 3,25 % от суммы, поэтому далёкий сосед почти не влияет. Классический K-NN дал бы классу «Средний» 3 голоса из 5 (60 %).

### Пример 3. Приоритет инцидента (нечёткие метки, $m=3$)

Признаки: $x_1$ — масштаб затронутых систем, $x_2$ — ценность актива. Обучающие объекты частично принадлежат нескольким классам. Параметр $m=3$, поэтому показатель степени в весе равен $\frac{2}{m-1}=1$. $K=4$.

| Объект | $x_1$ | $x_2$ | $u$(Критический) | $u$(Значимый) | $u$(Незначительный) |
| :----: | :---: | :---: | :--------------: | :-----------: | :-----------------: |
| P1 | 0,63 | 0,54 | 0,7 | 0,3 | 0,0 |
| P2 | 0,48 | 0,66 | 0,2 | 0,6 | 0,2 |
| P3 | 0,75 | 0,70 | 0,9 | 0,1 | 0,0 |
| P4 | 0,51 | 0,62 | 0,4 | 0,5 | 0,1 |
| P5 | 0,30 | 0,10 | 0,0 | 0,1 | 0,9 |

Классифицируемый инцидент: $x=(0{,}60;\ 0{,}50)$.

| Сосед | $d$ | Вес $1/(d+0{,}01)$ |
| :---: | :-: | :----------------: |
| P1 | 0,0500 | 16,6667 |
| P4 | 0,1500 | 6,2500 |
| P2 | 0,2000 | 4,7619 |
| P3 | 0,2500 | 3,8462 |
| **Сумма** | | **31,5248** |

Объект P5 (расстояние 0,5) в число четырёх ближайших не вошёл. Степени принадлежности учитывают нечёткие метки соседей:

```math
u_{\text{Критический}}=\frac{0{,}7\cdot16{,}6667+0{,}4\cdot6{,}25+0{,}2\cdot4{,}7619+0{,}9\cdot3{,}8462}{31{,}5248}=\frac{18{,}5807}{31{,}5248}=0{,}5894
```

```math
u_{\text{Значимый}}=\frac{11{,}3667}{31{,}5248}=0{,}3606,\qquad u_{\text{Незначительный}}=\frac{1{,}5774}{31{,}5248}=0{,}0500
```

**Результат:** «Критический» со степенью принадлежности **58,94 %**, при этом инцидент заметно принадлежит и классу «Значимый» (36,06 %). Для сравнения, при $m=2$ вес ближайшего соседа P1 растёт относительно остальных, и $u_{\text{Критический}}=0{,}5861$: чем меньше $m$, тем сильнее влияние ближайших соседей.

## Программная реализация

Программа написана на чистом Python 3, без библиотек машинного обучения: используется только стандартный модуль `math`. Это позволяет напрямую сопоставлять результаты программы с ручным расчётом. Обучающий объект — словарь с полями `name` (название), `features` (кортеж признаков) и `u` (словарь степеней принадлежности к классам).

| Функция | Что делает |
| ------- | ---------- |
| `euclidean_distance` | Евклидово расстояние между векторами признаков |
| `manhattan_distance` | Манхэттенское расстояние (сумма модулей разностей) |
| `make_sample` | Создаёт обучающий объект с чёткой меткой: 1 для своего класса, 0 для остальных |
| `find_neighbors` | Сортирует объекты по расстоянию и возвращает $K$ ближайших |
| `compute_weights` | Веса соседей $w_i=1/(d_i^{2/(m-1)}+\varepsilon)$ |
| `fuzzy_membership` | Степени принадлежности $u_j(x)=\sum u_{ij}w_i\,/\sum w_i$ |
| `fuzzy_knn` | Объединяет перечисленные функции, печатает промежуточные результаты, возвращает степени принадлежности и класс-победитель |
| `keller_init` | Строит нечёткие метки обучающих объектов по методу Келлера |

Метрика передаётся в `fuzzy_knn` параметром `metric`, поэтому для манхэттенского расстояния (варианты 11 и 12) достаточно указать `metric=manhattan_distance`. Веса и степени принадлежности считаются без промежуточного округления, поэтому результаты могут отличаться от ручных не более чем на $0{,}0001$ (например, сумма весов в примере 3: 31,5247 в программе и 31,5248 вручную).
