## Нечёткое множество

### Идея

В обычном (чётком) множестве элемент либо принадлежит множеству, либо нет. Нечёткое множество $A$ допускает **степень принадлежности** $\mu_A(x)\in[0,1]$: чем ближе значение к 1, тем сильнее элемент соответствует понятию, которое описывает множество. Так можно формально записать расплывчатые понятия вроде «комфортная температура» или «высокая нагрузка».

Нечёткое множество записывается как набор пар «степень / элемент»:

$$A=\{\mu_A(x_1)/x_1,\ \mu_A(x_2)/x_2,\ \dots,\ \mu_A(x_n)/x_n\}$$

### Характеристики

| Понятие | Формула | Смысл |
| ------- | :-----: | ----- |
| Носитель | $\mathrm{supp}A=\{x\mid\mu_A(x)>0\}$ | Элементы, которые принадлежат множеству хотя бы в какой-то степени |
| Высота | $h(A)=\max\limits_x\mu_A(x)$ | Наибольшая степень принадлежности |
| Нормализация | $\mu_{A_N}(x)=\dfrac{\mu_A(x)}{h(A)}$ | Приведение множества к высоте 1 |

Множество называют **нормальным**, если $h(A)=1$. При нормализации все степени делятся на высоту, поэтому для нормального множества $A_N=A$.

## Задание 1. Нечёткое множество

Множество описывает комфортную температуру воды в бассейне для плавания (в градусах Цельсия):

$$A=\{0/18,\ 0{,}15/20,\ 0{,}4/23,\ 0{,}7/26,\ 0{,}95/28,\ 1/30,\ 0{,}85/32,\ 0{,}5/34,\ 0{,}2/36,\ 0/38\}$$

Здесь $x$ — температура воды, $\mu_A(x)$ — степень комфортности. Наибольшая комфортность (1) достигается при 30 °C, к краям диапазона она убывает.

**Результаты:**

- носитель: $\mathrm{supp}A=\{20,\,23,\,26,\,28,\,30,\,32,\,34,\,36\}$ (температуры 18 и 38 исключены, так как $\mu=0$);
- высота: $h(A)=1$;
- нормализация: $\mu_{A_N}(x)=\mu_A(x)/1=\mu_A(x)$, то есть $A_N=A$, потому что множество уже нормальное.

Вывод программы:

```text
A = {18: 0, 20: 0.15, 23: 0.4, 26: 0.7, 28: 0.95, 30: 1, 32: 0.85, 34: 0.5, 36: 0.2, 38: 0}
suppA = {32, 34, 36, 20, 23, 26, 28, 30}
h(A) = 1
A_norm = {18: 0.0, 20: 0.15, 23: 0.4, 26: 0.7, 28: 0.95, 30: 1.0, 32: 0.85, 34: 0.5, 36: 0.2, 38: 0.0}
```

(`suppA` — это `set` в Python, поэтому порядок элементов при выводе произвольный).

## Нечёткий K-NN

### Идея

**Классический K-NN** находит $K$ ближайших соседей объекта и присваивает ему тот класс, за который «проголосовало» больше соседей. Такой выбор жёсткий: ответ — один класс, без оценки уверенности, а при равенстве голосов решение неоднозначно. Все соседи также считаются равноправными, хотя один может лежать почти рядом, а другой — на границе окрестности.

**Fuzzy K-NN** устраняет оба недостатка. Ближайшие соседи получают **веса**, которые убывают с расстоянием, и вместо одного класса объект получает вектор степеней принадлежности ко всем классам:

$$u(x)=\bigl(u_1(x),\,u_2(x),\,\dots,\,u_C(x)\bigr),\qquad u_j(x)\in[0,1],\qquad \sum_{j=1}^{C}u_j(x)=1$$

Решение принимается по наибольшей степени, а сама степень показывает уверенность классификации.

### Алгоритм

**Шаг 1. Поиск ближайших соседей.** Для классифицируемого объекта $x$ вычисляется расстояние до каждого объекта обучающей выборки. В работе используется евклидово расстояние:

$$d(x,x_i)=\sqrt{\sum_{k}\bigl(x_k-x_{i,k}\bigr)^2}$$

Расстояния сортируются по возрастанию, и выбираются $K$ ближайших объектов.

**Шаг 2. Веса соседей.** Каждому из $K$ соседей присваивается вес, обратно пропорциональный расстоянию:

$$w_i=\frac{1}{d(x,x_i)^{\frac{2}{m-1}}+\varepsilon}$$

где:

- $m>1$ — параметр нечёткости (обычно $m=2$); чем больше $m$, тем сильнее влияние дальних соседей и тем более «размытым» становится результат;
- $\varepsilon$ — малая константа (обычно $0{,}01$), которая защищает от деления на ноль, когда объект совпадает с соседом.

При $m=2$ показатель равен $\tfrac{2}{m-1}=2$, и формула принимает вид $w_i=\dfrac{1}{d^2+\varepsilon}$. Ближайший сосед получает наибольший вес, поэтому его мнение «весит» больше.

**Шаг 3. Степени принадлежности.** Степень принадлежности объекта $x$ классу $j$ — доля суммарного веса соседей, которые относятся к этому классу:

$$u_j(x)=\frac{\sum\limits_{i=1}^{K}u_{ij}\cdot w_i}{\sum\limits_{i=1}^{K}w_i}$$

где $u_{ij}$ — принадлежность $i$-го соседа классу $j$. Обучающие объекты имеют чёткую метку, поэтому $u_{ij}=1$, если сосед входит в класс $j$, и $0$ в противном случае. Тогда числитель — просто сумма весов соседей класса $j$.

**Шаг 4. Решение.** Объект относится к классу с наибольшей степенью принадлежности:

$$\hat{y}(x)=\arg\max_j\,u_j(x)$$

### Псевдокод

```text
для каждого объекта обучающей выборки:
    d[i] ← расстояние(x, объект i)
отсортировать объекты по d, взять K ближайших
для каждого соседа i:
    w[i] ← 1 / (d[i]^(2/(m-1)) + ε)
W ← сумма w[i]
для каждого класса j:
    u[j] ← (сумма w[i] по соседям класса j) / W
ответ ← класс с максимальным u[j], уверенность = u[j]
```

### Преимущества по сравнению с классическим K-NN

| | Классический K-NN | Fuzzy K-NN |
| - | :---------------: | :--------: |
| Вклад соседей | Равный (голосование) | Зависит от расстояния |
| Результат | Один класс | Степени принадлежности ко всем классам |
| Оценка уверенности | Нет | Есть ($u_j$ в процентах) |
| Равенство голосов | Требует правила разрешения | Разрешается весами |

## Задание 2. Классификация нагрузки на сервер

**Постановка.** Определить уровень нагрузки на сервер по трём нормированным признакам: загрузке процессора (CPU), оперативной памяти (RAM) и сети (Network). Классы: «Высокая», «Средняя», «Низкая».

**Обучающая выборка:**

| Объект | CPU ($x_1$) | RAM ($x_2$) | Network ($x_3$) | Класс |
| :----: | :---------: | :---------: | :-------------: | :---: |
| A | 0,85 | 0,80 | 0,90 | Высокая |
| B | 0,90 | 0,85 | 0,75 | Высокая |
| C | 0,50 | 0,55 | 0,45 | Средняя |
| D | 0,45 | 0,50 | 0,55 | Средняя |
| E | 0,15 | 0,20 | 0,10 | Низкая |

**Параметры:** $K=4$, $m=2$, $\varepsilon=0{,}01$.

**Классифицируемый сервер:** CPU = 0,55; RAM = 0,60; Network = 0,50.

### Шаг 1. Расстояния и соседи

| Объект | $d^2$ | $d$ | Класс | Ближайший? |
| :----: | :---: | :-: | :---: | :--------: |
| C | 0,0075 | 0,0866 | Средняя | да (1) |
| D | 0,0225 | 0,1500 | Средняя | да (2) |
| B | 0,2475 | 0,4975 | Высокая | да (3) |
| A | 0,2900 | 0,5385 | Высокая | да (4) |
| E | 0,4800 | 0,6928 | Низкая | нет |

Пример: $d^2(x,C)=(0{,}55-0{,}50)^2+(0{,}60-0{,}55)^2+(0{,}50-0{,}45)^2=0{,}0075$.

### Шаг 2. Веса

$$w=\frac{1}{d^2+0{,}01}$$

| Сосед | Расчёт | Вес |
| :---: | :----: | :-: |
| C | $1/(0{,}0075+0{,}01)=1/0{,}0175$ | 57,1429 |
| D | $1/(0{,}0225+0{,}01)=1/0{,}0325$ | 30,7692 |
| B | $1/(0{,}2475+0{,}01)=1/0{,}2575$ | 3,8835 |
| A | $1/(0{,}29+0{,}01)=1/0{,}3$ | 3,3333 |
| **Сумма** | | **95,1289** |

### Шаг 3. Степени принадлежности

| Класс | Соседи | Вклад | Принадлежность |
| :---: | :----: | :---: | :------------: |
| Средняя | C, D | $57{,}1429+30{,}7692=87{,}9121$ | $87{,}9121/95{,}1289=\mathbf{0{,}9241}$ |
| Высокая | B, A | $3{,}8835+3{,}3333=7{,}2168$ | $7{,}2168/95{,}1289=0{,}0759$ |
| Низкая | нет | 0 | 0 |

Сумма принадлежностей: $0{,}9241+0{,}0759+0=1$.

### Шаг 4. Решение

Сервер классифицируется как **«Средняя нагрузка»** с уверенностью **92,41 %**.

Здесь хорошо видно преимущество метода: среди четырёх соседей два принадлежат «Средней» (C, D) и два «Высокой» (B, A) нагрузке, то есть классический K-NN получил бы ничью 2:2. Fuzzy K-NN разрешает её весами: C и D находятся очень близко к объекту (расстояния 0,09 и 0,15), а B и A — далеко (около 0,5), поэтому их вклад в 12 раз меньше.

Вывод программы:

```text
Результат Fuzzy K-NN: Средняя с уверенностью 92.41%
Принадлежности: {'Средняя': 0.9241363325395431, 'Высокая': 0.07586366746045689}
```
