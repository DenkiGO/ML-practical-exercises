## Алгоритм Fuzzy C-Means

### Идея

В жёстком методе **K-Means** каждая точка принадлежит ровно одному кластеру. Граница между кластерами при этом проходит чётко, даже если данные перекрываются. **Fuzzy C-Means** допускает **нечёткую принадлежность**: каждая точка $x_i$ принадлежит каждому кластеру $j$ со степенью $u_{ij}\in[0,1]$, причём сумма степеней по всем кластерам равна 1:

$$\sum_{j=1}^{c}u_{ij}=1\quad\text{для каждой точки } i$$

Точка, лежащая у центра кластера, принадлежит ему почти полностью, а точка между двумя кластерами делит принадлежность между ними. Это удобно, когда границы кластеров размыты.

### Обозначения и параметры

| Обозначение | Смысл |
| :---------: | ----- |
| $n$ | Число точек данных (здесь 10) |
| $c$ | Число кластеров (здесь 3) |
| $x_i$ | Координата $i$-й точки |
| $c_j$ | Центр (центроид) $j$-го кластера |
| $u_{ij}$ | Степень принадлежности точки $i$ кластеру $j$ |
| $d_{ij}=\left|x_i-c_j\right|$ | Расстояние от точки до центра кластера |
| $m$ | Коэффициент нечёткости, $m>1$ (здесь $m=2$) |
| $\varepsilon$ | Порог остановки (здесь $0{,}01$) |

Чем ближе $m$ к 1, тем «жёстче» кластеры (в пределе получается K-Means), чем больше $m$, тем размытее принадлежности.

### Целевая функция

FCM минимизирует взвешенную сумму квадратов расстояний от точек до центров:

$$J=\sum_{i=1}^{n}\sum_{j=1}^{c}u_{ij}^{m}\,\left|x_i-c_j\right|^2\ \to\ \min$$

Расстояния до далёких центров умножаются на малые $u_{ij}^m$, поэтому на значение $J$ они почти не влияют. Минимум ищется итеративно: попеременно фиксируются то центры, то матрица $U$.

### Шаги алгоритма

**Шаг 1. Инициализация.** Задаётся начальная матрица принадлежностей $U^{(0)}$ размером $n\times c$, у которой сумма в каждой строке равна 1. В работе она задана вручную (таблица ниже).

**Шаг 2. Расчёт центров.** Центр кластера — среднее всех точек, взвешенное степенями принадлежности в степени $m$:

$$c_j=\frac{\sum\limits_{i=1}^{n}u_{ij}^{m}\cdot x_i}{\sum\limits_{i=1}^{n}u_{ij}^{m}}$$

Точки с большой принадлежностью сильнее тянут центр на себя, а точки с малой почти не влияют. Возведение в степень $m$ усиливает этот эффект.

**Шаг 3. Расчёт расстояний.** Для каждой точки вычисляется расстояние до каждого центра: $d_{ij}=\left|x_i-c_j\right|$.

**Шаг 4. Обновление матрицы принадлежностей.** Принадлежность определяется относительной близостью точки к центрам:

$$u_{ij}=\frac{1}{\sum\limits_{k=1}^{c}\left(\dfrac{d_{ij}}{d_{ik}}\right)^{\frac{2}{m-1}}}$$

При $m=2$ показатель степени равен 2. Чем меньше расстояние $d_{ij}$ по сравнению с расстояниями до других центров, тем меньше сумма в знаменателе и тем больше $u_{ij}$. Сумма $u_{ij}$ по $j$ при этом автоматически равна 1.

*Частный случай.* Если точка совпала с центром ($d_{ij}=0$), деление на ноль невозможно: принимается $u_{ij}=1$, а остальные принадлежности этой точки равны 0.

**Шаг 5. Проверка остановки.** Если наибольшее изменение элементов матрицы $U$ меньше порога,

$$\max_{i,j}\left|u_{ij}^{new}-u_{ij}^{old}\right|<\varepsilon,$$

алгоритм останавливается. Иначе шаги 2–5 повторяются с новой матрицей. В программе дополнительно задано ограничение числа итераций (`max_iter=100`).

**Шаг 6. Результат.** Выводятся финальная матрица $U$ и центры кластеров. Если нужно жёсткое разбиение, каждая точка относится к кластеру с наибольшей принадлежностью: $\arg\max_j u_{ij}$.

### Псевдокод

```text
U ← начальная матрица принадлежностей (сумма по строке = 1)
повторять до max_iter раз:
    для каждого кластера j:
        c[j] ← Σ (U[i][j]^m · x[i]) / Σ (U[i][j]^m)
    для каждой точки i и кластера j:
        d[i][j] ← |x[i] − c[j]|
    для каждой точки i:
        если какое-то d[i][j] = 0:  U_new[i][j] ← 1, остальные ← 0
        иначе:  U_new[i][j] ← 1 / Σ_k (d[i][j] / d[i][k])^(2/(m−1))
    если max |U_new − U| < ε:  остановиться
    U ← U_new
```

### Сравнение с K-Means

| | K-Means | Fuzzy C-Means |
| - | :-----: | :-----------: |
| Принадлежность точки | Ровно один кластер (0 или 1) | Степень $u_{ij}\in[0,1]$ для всех кластеров |
| Пограничные точки | Относятся к одному кластеру | Делят принадлежность между кластерами |
| Вклад точки в центр | Только в «свой» кластер | Во все кластеры, пропорционально $u_{ij}^m$ |
| Дополнительный параметр | Нет | Коэффициент нечёткости $m$ |
| Подходит для | Чётко разделённых данных | Перекрывающихся кластеров |

### Итерация 1

**Центры кластеров.** Для кластера 1:

$$\text{числитель}=0{,}7^2\cdot1+0{,}6^2\cdot2+0{,}4^2\cdot4+0{,}3^2\cdot5+\dots+0{,}02^2\cdot14=2{,}5133$$

$$\text{знаменатель}=0{,}49+0{,}36+0{,}16+0{,}09+0{,}01+0{,}01+0{,}0025+0{,}0025+0{,}0004+0{,}0004=1{,}1258$$

$$c_1=\frac{2{,}5133}{1{,}1258}\approx2{,}23$$

Аналогично для остальных кластеров: $c_2=\dfrac{9{,}0533}{1{,}3738}\approx6{,}59$, $c_3=\dfrac{30{,}95}{2{,}65}\approx11{,}68$.

**Новые принадлежности.** Для точки $x_1=1$ расстояния до центров: $d_{11}=1{,}23$, $d_{12}=5{,}59$, $d_{13}=10{,}68$. Тогда

$$u_{11}=\frac{1}{1+\left(\frac{1{,}23}{5{,}59}\right)^2+\left(\frac{1{,}23}{10{,}68}\right)^2}=\frac{1}{1+0{,}0484+0{,}0132}\approx0{,}942$$

$$u_{12}=\frac{1}{\left(\frac{5{,}59}{1{,}23}\right)^2+1+\left(\frac{5{,}59}{10{,}68}\right)^2}\approx0{,}046,\qquad u_{13}\approx0{,}012$$

Сумма: $0{,}942+0{,}046+0{,}012=1$. Для остальных точек расчёт выполняется так же.

## Задание 2. Функции принадлежности

**Постановка.** Придумать три формулировки и отобразить их на графике классов. Выбрана загрузка процессора, выраженная в процентах:

1. Низкая загрузка процессора (характерная точка 10 %);
2. Средняя загрузка процессора (50 %);
3. Высокая загрузка процессора (85 %).

Для каждого понятия выбран свой стандартный вид функции принадлежности:

| Понятие | Вид | Параметры | Формула |
| ------- | --- | :-------: | ------- |
| Низкая | L-образная (убывающая) | $a=10,\ b=50$ | $\mu(x)=\begin{cases}1,&x\le a\\ \dfrac{b-x}{b-a},&a<x\le b\\ 0,&x>b\end{cases}$ |
| Средняя | Треугольная | $a=10,\ b=50,\ c=85$ | $\mu(x)=\max\left(0,\ \min\left(\dfrac{x-a}{b-a},\ \dfrac{c-x}{c-b}\right)\right)$ |
| Высокая | Гамма-образная (возрастающая) | $a=50,\ b=85$ | $\mu(x)=\begin{cases}0,&x\le a\\ \dfrac{x-a}{b-a},&a<x\le b\\ 1,&x>b\end{cases}$ |

Степень принадлежности «средней» загрузки равна 1 только в точке 50 %, а у «низкой» и «высокой» плато ($\mu=1$) находится на краях шкалы. На графике три функции перекрываются, поэтому одно значение загрузки может относиться сразу к двум понятиям. Например (по формулам):

| Загрузка $x$ | Низкая | Средняя | Высокая |
| :----------: | :----: | :-----: | :-----: |
| 10 % | 1 | 0 | 0 |
| 30 % | 0,5 | 0,5 | 0 |
| 50 % | 0 | 1 | 0 |
| 70 % | 0 | 0,4286 | 0,5714 |
| 85 % | 0 | 0 | 1 |

## Программа

### Задание 1 (`lab_2.py`)

| Элемент | Что делает |
| ------- | ---------- |
| `fuzzy_c_means(X, c, m, epsilon, max_iter)` | Основная функция: возвращает матрицу $U$, центры и число итераций |
