## Кластеризация

**Кластеризация** — задача обучения без учителя: разбить объекты на группы (кластеры) так, чтобы объекты внутри группы были похожи друг на друга, а объекты из разных групп — отличались. Метки классов заранее неизвестны, алгоритм ищет структуру в самих данных.

Два метода из работы решают её по-разному:

| | Граф с порогом $R$ | k-средних |
| - | ------------------ | --------- |
| Входные данные | Матрица попарных расстояний | Координаты объектов |
| Параметр | Радиус $R$ | Число кластеров $k$ и начальные центры |
| Число кластеров | Определяется автоматически | Задаётся заранее |
| Идея | Близкие объекты связываются ребром, кластер — связная компонента | Кластер — «облако» вокруг центра |

## Часть 1. Кластеризация графа по порогу $R$

### Идея

Объекты представляются **вершинами графа**, расстояния между ними — **весами рёбер**. Объекты считаются «соседями», если расстояние между ними не больше радиуса $R$. Остальные рёбра отбрасываются, а кластером становится **компонента связности** — группа вершин, между любыми двумя из которых есть путь по оставшимся рёбрам.

Объекты не обязаны быть близки напрямую: достаточно цепочки «соседей». Если $A$ близко к $B$, а $B$ близко к $C$, то $A$, $B$ и $C$ окажутся в одном кластере, даже если $d(A,C)>R$.

### Алгоритм по шагам

1. **Построение графа.** Для каждой пары объектов $(a,b)$ с расстоянием $d(a,b)\le R$ добавляется ребро $a\!-\!b$. Рёбра с $d>R$ отбрасываются.
2. **Список смежности.** Для каждой вершины хранится список её соседей.
3. **Поиск компонент обходом в глубину (DFS).** Берётся первая непосещённая вершина, и из неё обходом в глубину помечаются все достижимые вершины. Они образуют один кластер.
4. **Повтор.** Пункт 3 повторяется для следующей непосещённой вершины, пока не будут обработаны все. Одиночные вершины без рёбер образуют кластеры из одного объекта.

Число кластеров получается автоматически и зависит только от $R$: чем больше $R$, тем больше рёбер и тем крупнее кластеры.

## Часть 2. Метод k-средних

### Идея

**k-means** разбивает объекты на $k$ кластеров, у каждого из которых есть **центр** (центроид). Объект относится к кластеру, центр которого ближе. Затем центры сдвигаются в середину своих кластеров, объекты перераспределяются заново, и так до тех пор, пока разбиение не перестанет меняться.

### Что минимизируется

Метод минимизирует суммарное квадратичное отклонение точек от центров своих кластеров:

$$J=\sum_{j=1}^{k}\ \sum_{x_i\in S_j}\lVert x_i-\mu_j\rVert^2$$

где $S_j$ — множество точек кластера $j$, $\mu_j$ — его центр.

### Формулы

| Величина | Формула |
| -------- | ------- |
| Евклидово расстояние | $d(p,c)=\sqrt{(p_x-c_x)^2+(p_y-c_y)^2}$ |
| Центр кластера | $\mu_j=\dfrac{1}{n_j}\sum_{x_i\in S_j}x_i$ (среднее координат), $n_j$ — число точек кластера |

### Алгоритм по шагам

1. **Инициализация.** Выбираются $k$ начальных центров. В работе это объекты $A(4;2)$ и $D(1;1)$.
2. **Назначение.** Для каждой точки считаются расстояния до всех центров, и точка относится к кластеру с ближайшим центром. При равенстве расстояний выбирается кластер 1.
3. **Пересчёт центров.** Новый центр каждого кластера — среднее арифметическое координат его точек.
4. **Проверка сходимости.** Если центры не изменились, алгоритм завершается. Иначе шаги 2–3 повторяются (но не более 20 раз).

Каждый шаг не увеличивает $J$: назначение к ближайшему центру уменьшает отклонения, а среднее — это точка, минимизирующая сумму квадратов расстояний. Поскольку число разбиений конечно, алгоритм всегда останавливается, но может найти **локальный** минимум, зависящий от начальных центров.

## Результаты

### Задание 1

Из всех пар условию $d\le2$ удовлетворяет только одна: $B\!-\!D$ ($d=2$). Остальные рёбра удаляются.

```text
A    B — D    C    E
```

Кластеры: $\{A\}$, $\{B,D\}$, $\{C\}$, $\{E\}$.

**Вывод.** Объект $A$ образует отдельный кластер, **ни один объект** не попадает с ним в один кластер.

### Задание 2

**Итерация 1.** Центры $C_1=(4;2)$, $C_2=(1;1)$:

| Точка | $d(C_1)$ | $d(C_2)$ | Кластер |
| :---: | :------: | :------: | :-----: |
| A | 0,00 | 3,16 | 1 |
| B | 1,00 | 2,24 | 1 |
| C | 4,24 | 2,00 | 2 |
| D | 3,16 | 0,00 | 2 |
| E | 3,61 | 3,00 | 2 |

Новые центры: $C_1=\left(\dfrac{4+3}{2};\dfrac{2+2}{2}\right)=(3{,}5;\ 2)$, $C_2=\left(\dfrac{1+1+1}{3};\dfrac{-1+1+4}{3}\right)=(1;\ 1{,}33)$.

**Итерация 2.** Центры $C_1=(3{,}5;\ 2)$, $C_2=(1;\ 1{,}33)$:

| Точка | $d(C_1)$ | $d(C_2)$ | Кластер |
| :---: | :------: | :------: | :-----: |
| A | 0,50 | 3,07 | 1 |
| B | 0,50 | 2,11 | 1 |
| C | 3,91 | 2,33 | 2 |
| D | 2,69 | 0,33 | 2 |
| E | 3,20 | 2,67 | 2 |

Разбиение не изменилось, центры остались прежними — алгоритм **сошёлся за 2 итерации**.

**Итог:**

- кластер 1: $\{A,\,B\}$, центр $(3{,}5;\ 2)$;
- кластер 2: $\{C,\,D,\,E\}$, центр $(1;\ 1{,}33)$;
- суммарное квадратичное отклонение $J\approx13{,}17$ ($0{,}5$ в первом кластере и $\approx12{,}67$ во втором).
