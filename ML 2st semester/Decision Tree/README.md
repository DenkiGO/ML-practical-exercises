## Теоретический обзор и алгоритмы

### Дерево решений (Decision Tree)

Дерево решений — метод машинного обучения для задач классификации и регрессии, представляющий модель в виде древовидной структуры. Каждый внутренний узел содержит условие проверки признака, ветви соответствуют исходам проверки, а конечные узлы (листья) содержат целевые классы.

Основная цель при построении дерева — последовательно разбивать исходный датасет на всё более «чистые» подмножества, содержащие преимущественно объекты одного класса.

---

### Индекс неопределённости Джини (Gini Impurity)

Индекс Джини оценивает степень неоднородности (неопределённости) подмножества. Чем меньше значение индекса, тем выше чистота узла.

#### 1. Формула Джини для узла

Общая формула неопределённости Джини для $k$ классов:


$$\text{Gini} = 1 - \sum_{i=1}^{k} p_i^2$$


где $p_i$ — вероятность (доля) объектов класса $i$ в рассматриваемом узле.

Для бинарной классификации ($Y \in \{0, 1\}$):


$$\text{Gini} = 1 - p_0^2 - p_1^2$$

#### 2. Взвешенная неопределённость при ветвлении

При разбиении узла по признаку $P$, принимающему значения $v$, суммарная неопределённость рассчитывается как взвешенная сумма неопределённостей получаемых веток:


$$\text{Gini}(P) = \sum_{v} \Pr(P=v) \cdot \text{Gini}(P=v)$$

Эквивалентная форма расчета вклада ветки для бинарной классификации:


$$\text{Gini}(P) = \sum_{v} \Pr(P=v) \cdot \Pr(Y=0 \mid P=v) \cdot \Pr(Y=1 \mid P=v)$$

#### 3. Критерий выбора лучшего признака

Признак $P^*$ для очередного ветвления выбирается по правилу минимизации взвешенной неопределённости:


$$P^* = \arg\min_P \text{Gini}(P)$$

---

### Алгоритм реализации в коде (`gini_for_feature`)

1. **Группировка объектов:** Исходная выборка разделяется на подмножества по возможным значениям признака ($0$ и $1$).
2. **Расчет вероятностей веток:** Для каждого значения признака $v$ определяется его вероятность появления $\Pr(P=v) = \frac{m}{N}$, где $m$ — количество объектов в ветке, $N$ — общее число объектов.
3. **Расчет вероятностей классов внутри веток:** Для каждой ветки подсчитываются доли объектов класса 0 и класса 1: $\Pr(Y=0 \mid P=v)$ и $\Pr(Y=1 \mid P=v)$.
4. **Суммирование вкладов:** Вычисляется вклад каждой ветки как произведение $\Pr(P=v) \cdot p_0 \cdot p_1$ и суммируется в общий показатель $\text{Gini}(P)$.
5. **Выбор ветвления:** Сравниваются показатели всех признаков и выбирается признак с наименьшим значением Джини.

## Задача и исходные данные

Вариант №3. Дана обучающая выборка из 4 объектов с бинарными признаками $P_1, P_2, P_3$ и целевым классом $Y$:

| Объект | $P_1$ | $P_2$ | $P_3$ | $Y$ |
| --- | --- | --- | --- | --- |
| **A** | 1 | 1 | 1 | 0 |
| **B** | 0 | 0 | 1 | 1 |
| **C** | 1 | 1 | 0 | 0 |
| **D** | 1 | 1 | 0 | 1 |

**Требуется:** найти значения неопределенности Джини для каждого нецелевого признака и построить дерево решений.

---

## Пошаговый расчет и результаты

### 1. Расчет индекса Джини для корневого узла

* **Признак $P_1$:**
* Ветка $P_1 = 0$ (объект B, $Y=1$): $\Pr(P_1=0) = \frac{1}{4}$, $p_0 = 0$, $p_1 = 1 \implies \text{Вклад} = \frac{1}{4} \cdot 0 \cdot 1 = 0$
* Ветка $P_1 = 1$ (объекты A, C, D, $Y=\{0, 0, 1\}$): $\Pr(P_1=1) = \frac{3}{4}$, $p_0 = \frac{2}{3}$, $p_1 = \frac{1}{3} \implies \text{Вклад} = \frac{3}{4} \cdot \frac{2}{3} \cdot \frac{1}{3} = \frac{1}{6}$
* **$\text{Gini}(P_1) = 0 + \frac{1}{6} \approx 0.167$**


* **Признак $P_2$:**
* Распределение совпадают с $P_1$, следовательно:
* **$\text{Gini}(P_2) = \frac{1}{6} \approx 0.167$**


* **Признак $P_3$:**
* Ветка $P_3 = 0$ (объекты C, D, $Y=\{0, 1\}$): $\Pr(P_3=0) = \frac{2}{4}$, $p_0 = \frac{1}{2}$, $p_1 = \frac{1}{2} \implies \text{Вклад} = \frac{1}{2} \cdot \frac{1}{4} = \frac{1}{8}$
* Ветка $P_3 = 1$ (объекты A, B, $Y=\{0, 1\}$): $\Pr(P_3=1) = \frac{2}{4}$, $p_0 = \frac{1}{2}$, $p_1 = \frac{1}{2} \implies \text{Вклад} = \frac{1}{8}$
* **$\text{Gini}(P_3) = \frac{1}{8} + \frac{1}{8} = \frac{1}{4} = 0.250$**



**Вывод первого уровня:** Признаки $P_1$ и $P_2$ обладают одинаковым минимальным значением неопределенности ($\approx 0.167$). Выбираем $P_1$ в качестве корня дерева.

---

### 2. Второе ветвление ($P_1 = 1$)

В ветку $P_1 = 1$ входят объекты A, C, D ($Y=\{0, 0, 1\}$):

* Признак $P_2$ принимает одинаковое значение ($1$) для всех объектов, поэтому дальнейшее разбиение по нему невозможно ($\text{Gini}(P_2 \mid P_1=1) \approx 0.222$).
* Для признака $P_3$:
* Ветка $P_3 = 1$ (объект A, $Y=0$): $\text{Вклад} = 0$ (чистый лист)
* Ветка $P_3 = 0$ (объекты C, D, $Y=\{0, 1\}$): $\text{Вклад} = \frac{2}{3} \cdot \frac{1}{2} \cdot \frac{1}{2} = \frac{1}{6}$
* **$\text{Gini}(P_3 \mid P_1=1) = \frac{1}{6} \approx 0.167$**



После ветвления по $P_3$ объекты C и D имеют идентичные признаки $(P_1=1, P_2=1, P_3=0)$, но противоположные классы $Y$, что делает их дальнейшее строгое разделение невозможным.

---

### Результирующее дерево решений

```text
             /      \

          /            \
    Leaf: Y=0      Leaf: Y=0|1

```
