## Логистическая регрессия

### Идея

**Логистическая регрессия** — метод классификации, который оценивает **вероятность** принадлежности объекта к классу. В отличие от линейной регрессии, результат всегда лежит в интервале $(0;1)$, поэтому его можно трактовать как вероятность, а для получения класса сравнить с порогом (обычно $0{,}5$).

Модель состоит из двух частей:

1. **Линейная комбинация признаков** — взвешенная сумма, которая может принимать любые значения:

$$z=w_0+w_1x_1+\dots+w_nx_n$$

2. **Сигмоида** — функция, которая «сжимает» $z$ в интервал $(0;1)$:

$$p=\sigma(z)=\frac{1}{1+e^{-z}}$$

При $z=0$ вероятность равна $0{,}5$. Чем больше $z$, тем ближе $p$ к 1, чем меньше, тем ближе к 0. В работе один признак $x$ (длина письма), поэтому $z=w_0+w_1x$, а граница классов — точка $x=-w_0/w_1$.

### Функция потерь

Качество модели измеряется **бинарной кросс-энтропией** (log loss) для истинной метки $y\in\{0,1\}$ и предсказанной вероятности $p$:

$$L=-\bigl[y\ln p+(1-y)\ln(1-p)\bigr]$$

Смысл: если $y=1$, остаётся слагаемое $-\ln p$, которое велико, когда модель даёт малую вероятность. Если $y=0$, остаётся $-\ln(1-p)$, которое велико, когда модель уверенно предсказывает 1. Чем увереннее ошибка, тем сильнее штраф. Средняя ошибка по выборке из $n$ объектов:

$$\overline{L}=\frac1n\sum_{j=1}^{n}L_j$$

## Алгоритм по шагам

Параметры $w_0$ и $w_1$ подбираются **стохастическим градиентным спуском**: на каждом шаге берётся один объект выборки, считается ошибка на нём, и веса сдвигаются против градиента.

### 1. Инициализация

Задаются начальные веса $w_0=0$, $w_1=0{,}2$ и скорость обучения $\eta=0{,}01$.

### 2. Прямой проход

Для текущего объекта $x_i$ вычисляется вероятность:

$$z=w_0+w_1x_i,\qquad p=\sigma(z)$$

### 3. Оценка качества

Для всех объектов выборки считается ошибка $L_j$ и средняя ошибка $\overline{L}$. Она нужна для контроля обучения и критерия остановки.

### 4. Градиенты

Ошибка зависит от весов через цепочку $w\to z\to p\to L$, поэтому по правилу цепочки:

$$\frac{\partial L}{\partial w_k}=\frac{\partial L}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial w_k}$$

| Звено цепочки | Формула |
| ------------- | ------- |
| $\dfrac{\partial p}{\partial z}$ | $p(1-p)$ — производная сигмоиды |
| $\dfrac{\partial z}{\partial w_0}$ | $1$ |
| $\dfrac{\partial z}{\partial w_1}$ | $x_i$ |

Для кросс-энтропии $\dfrac{\partial L}{\partial p}=\dfrac{p-y}{p(1-p)}$, и после умножения на $\dfrac{\partial p}{\partial z}$ множитель $p(1-p)$ сокращается:

$$\frac{\partial L}{\partial z}=p-y,\qquad \frac{\partial L}{\partial w_0}=p-y,\qquad \frac{\partial L}{\partial w_1}=(p-y)\,x_i$$

Это главное преимущество кросс-энтропии: градиент пропорционален ошибке $p-y$ и не затухает, когда сигмоида насыщена.

### 5. Обновление весов

$$w_k^{new}=w_k^{old}-\eta\,\frac{\partial L}{\partial w_k}$$

### 6. Следующий объект и остановка

Объекты берутся по кругу: $x_1,\,x_2,\dots,x_5,\,x_1,\dots$ Шаги 2–5 повторяются, пока средняя ошибка $\overline{L}$ не станет меньше порога $0{,}9$ или не будет выполнено 1000 шагов.

### 7. Предсказание

Для нового письма длиной $x$ слов вероятность отклика равна $\sigma(w_0+w_1x)$.

## Задача и данные

Оценить вероятность отклика на email, если длина письма равна **90 слов**. Признак — длина письма в словах, $y=1$ — письмо привело к отклику, $y=0$ — нет.

| № | Длина письма $x$ | Отклик $y$ |
| - | :-: | :-: |
| 1 | 50 | 0 |
| 2 | 100 | 1 |
| 3 | 20 | 0 |
| 4 | 80 | 1 |
| 5 | 300 | 0 |

Начальные веса $w_0=0$, $w_1=0{,}2$ дают $p\approx1$ почти для всех объектов (для письма из 20 слов $p\approx0{,}982$), то есть модель с самого начала «считает» все письма успешными, и ошибки на объектах класса 0 велики.

## Программа

| Функция | Что делает |
| ------- | ---------- |
| `sigmoid` | Сигмоида $\sigma(z)=\dfrac{1}{1+e^{-z}}$ |
| `binary_cross_entropy` | Ошибка $L$ для одного объекта; вероятность ограничивается интервалом $[10^{-10};\,1-10^{-10}]$, чтобы избежать $\ln 0$ |
| `predict` | Вероятность отклика для длины письма $X$ |
| `binary_cross_entropy_from_z` | Устойчивая форма ошибки через $z$: $\ln(1+e^{z})-yz$ (в основном цикле не используется) |

Основной цикл: на каждом шаге выбирается следующий объект, считаются $z$ и $p$, средняя ошибка по всей выборке, градиенты, затем обновляются веса. Цикл останавливается при $\overline{L}<0{,}9$.

## Результаты

Начало обучения (средняя ошибка при начальных весах $\approx7{,}41$):

| Итерация | Объект | $x$ | $y$ | $p$ | $w_0$ | $w_1$ | $\overline{L}$ |
| :------: | :----: | :-: | :-: | :-: | :---: | :---: | :------------: |
| 1 | 1 | 50 | 0 | 1,0000 | −0,000000 | 0,199977 | 7,4088 |
| 2 | 2 | 100 | 1 | 1,0000 | −0,000000 | 0,199977 | 7,4085 |
| 3 | 3 | 20 | 0 | 0,9820 | −0,000174 | 0,196507 | 7,4085 |

| 5 | 5 | 300 | 0 | 1,0000 | −0,000174 | 0,196507 | 7,3601 |

Цикл остановился на **97-й итерации**, когда средняя ошибка опустилась до $0{,}851<0{,}9$.

**Итог:**

- веса: $w_0\approx-0{,}0116$, $w_1\approx0{,}0990$;
- вероятность отклика на письмо длиной 90 слов: $z\approx8{,}90$, $p\approx0{,}9999$.
