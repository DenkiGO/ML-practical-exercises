## Цель

Изучить принцип работы алгоритма адаптивного бустинга **AdaBoost** на примере бинарной классификации. Разобрать последовательное изменение весов обучающих объектов, вычисление весов базовых классификаторов и нормировку распределения весов после каждой итерации.

## Идея алгоритма

**AdaBoost** объединяет несколько простых классификаторов в один ансамбль. Каждый классификатор получает свой вес — «голос» в итоговом решении. При этом алгоритм учитывает, на каких объектах текущий классификатор ошибся: после очередного шага веса таких объектов относительно увеличиваются, поэтому следующие шаги сильнее учитывают трудные примеры.

В этой работе используются биполярные метки:

$$y_i,\ C_j(x_i)\in\{-1,+1\}$$

Здесь $y_i$ — правильный класс объекта, а $C_j(x_i)$ — ответ классификатора $C_j$.

## Формулы

| Величина | Формула | Смысл |
| -------- | ------- | ----- |
| Начальные веса объектов | $u_i^{(1)}=\frac{1}{N}$ | Все объекты изначально равнозначны |
| Ошибка классификатора | $\varepsilon_j=\sum_{i:C_j(x_i)\ne y_i}u_i$ | Сумма весов объектов, на которых есть ошибка |
| Вес классификатора | $\alpha_j=\frac12\ln\frac{1-\varepsilon_j}{\varepsilon_j}$ | Чем меньше ошибка, тем больше вклад классификатора |
| Обновление веса объекта | $\widetilde u_i=u_i\exp(-\alpha_j y_i C_j(x_i))$ | Изменение веса с учётом правильности ответа |
| Нормировка | $u_i'=\frac{\widetilde u_i}{\sum_k\widetilde u_k}$ | Сумма весов снова становится равной 1 |
| Итоговый ответ | $\hat y_i=\operatorname{sign}\left(\sum_j\alpha_j C_j(x_i)\right)$ | Класс определяется знаком взвешенной суммы |

Если классификатор ошибся на объекте, произведение $y_iC_j(x_i)=-1$, поэтому его вес увеличивается перед нормировкой. Если классификатор ответил правильно, произведение равно $+1$ и вес объекта уменьшается. После нормировки относительное влияние ошибок становится заметнее.

В программе предусмотрена отдельная обработка случая $\varepsilon_j=0$: вес такого классификатора задаётся равным `1.0`, чтобы не вычислять логарифм с нулём в знаменателе.

## Алгоритм по шагам

1. **Подготовка данных.** Для каждого из 7 объектов заданы ответы трёх классификаторов `C1`, `C2`, `C3` и истинная метка `Y`. Значения `+1` и `-1` обозначают два класса.
2. **Инициализация весов.** Всем объектам назначается одинаковый вес $1/7\approx0{,}143$.
3. **Выбор классификатора текущей итерации.** На итерациях 1, 2 и 3 программа последовательно использует `C1`, `C2` и `C3`.
4. **Расчёт ошибки.** Программа проходит по объектам и складывает их текущие веса, если ответ выбранного классификатора не совпадает с `Y`. Полученная сумма — $\varepsilon_j$.
5. **Расчёт голоса классификатора.** По ошибке вычисляется $\alpha_j=\frac12\ln\frac{1-\varepsilon_j}{\varepsilon_j}$. Это значение сохраняется для итогового ансамбля.
6. **Обновление весов объектов.** Для каждого объекта вычисляется $\widetilde u_i=u_i\exp(-\alpha_j y_i C_j(x_i))$. Ошибочно классифицированные объекты получают больший ненормированный вес, а правильно классифицированные — меньший.
7. **Нормировка.** Все новые веса делятся на их сумму. Полученное распределение используется на следующей итерации.
8. **Итоговая классификация.** После трёх итераций для каждого объекта вычисляется взвешенная сумма $\alpha_1C_1+\alpha_2C_2+\alpha_3C_3$. Если сумма строго больше нуля, программа выбирает класс `+1`; иначе — `-1`.
9. **Вывод.** В консоль выводятся ошибка и вес каждого классификатора, нормированные веса объектов после каждой итерации и результат классификации каждого объекта.

Важно: в данном скрипте три базовых классификатора заранее заданы и обрабатываются по очереди. Программа не ищет новый классификатор на каждой итерации — она обновляет распределение весов для `C1`, затем `C2`, затем `C3`.

## Реализация в программе

Скрипт `lab_7.py` реализует расчёт трёх итераций AdaBoost.

| Элемент программы | Назначение |

## Результаты

При запуске приведённого в отчёте кода получаются следующие значения (округление до трёх знаков):

| Итерация | Классификатор | Ошибка $\varepsilon$ | Вес $\alpha$ |
| :------: | :-----------: | :------------------: | :----------: |
| 1 | `C1` | 0.429 | 0.144 |
| 2 | `C2` | 0.125 | 0.973 |
| 3 | `C3` | 0.238 | 0.582 |

После третьей итерации нормированные веса объектов приблизительно равны:

```text
[0.062, 0.200, 0.150, 0.062, 0.328, 0.150, 0.047]
```

Самый большой вес получает объект 5, поскольку классификатор `C2` ошибается именно на нём. Это показывает, как алгоритм усиливает внимание к объектам, которые сложнее классифицировать.

Итоговая взвешенная сумма для объекта 5 отрицательна, поэтому программа относит его к классу `-1`, хотя истинная метка равна `+1`. Следовательно, в этой реализации ансамбль не классифицирует все объекты без ошибок.
