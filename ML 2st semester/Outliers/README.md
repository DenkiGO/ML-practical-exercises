## Выбросы

**Выброс** — объект выборки, который заметно отличается от остальных: он либо находится далеко от большинства объектов, либо имеет значение признака вне типичного диапазона. Выбросы могут быть ошибками измерения, а могут быть редкими, но реальными событиями (например, аномальная активность в сетевом трафике), поэтому их важно уметь находить до построения модели. Они искажают среднее значение, дисперсию и расстояния между объектами, а значит, и результаты кластеризации и классификации.

В работе рассмотрены два подхода:

| | Метод суммы расстояний | Квартильный критерий (правило Тьюки) |
| - | ---------------------- | ------------------------------------- |
| Что анализируется | Объекты с несколькими признаками | Значения одного признака |
| Идея | Выброс — объект, наиболее удалённый от всех остальных | Выброс — значение, далеко выходящее за «центральную часть» распределения |
| Исходные данные | Координаты объектов | Квартили $Q_{25}$ и $Q_{75}$ |
| Результат | Выброс среди объектов | Интервалы значений, считающиеся выбросами |

## Метод 1. Сумма манхэттенских расстояний

### Манхэттенское расстояние (L1)

Расстояние между точками $x=(x_1,\dots,x_n)$ и $y=(y_1,\dots,y_n)$ — сумма модулей разностей по всем признакам:

$$d(x,y)=\sum_{i=1}^{n}\lvert x_i-y_i\rvert$$

Название связано с кварталами Манхэттена: путь между двумя точками идёт по прямоугольной сетке улиц, а не по прямой. L1 меньше реагирует на большие отклонения по одному признаку, чем евклидова метрика, потому что разности не возводятся в квадрат.

### Идея

Чем сильнее объект отличается от остальных, тем больше его расстояния до них. Поэтому для каждого объекта считается **суммарное расстояние до всех остальных**, и выбросом объявляется объект с наибольшей суммой:

$$S_k=\sum_{j\ne k}d(x_k,x_j),\qquad \text{выброс}=\arg\max_k S_k$$

### Алгоритм по шагам

1. **Попарные расстояния.** Для каждой пары объектов вычисляется манхэттенское расстояние. Матрица расстояний симметрична ($d(x,y)=d(y,x)$), а на диагонали стоят нули.
2. **Суммы расстояний.** Для каждого объекта $k$ складываются его расстояния до всех остальных объектов: $S_k$.
3. **Поиск максимума.** Находится наибольшая сумма $S_{max}$.
4. **Вывод.** Выбросами считаются все объекты, у которых $S_k=S_{max}$.

## Метод 2. Квартильный критерий (правило Тьюки)

### Идея

Квартили делят упорядоченную выборку на четыре равные по числу значений части:

- $Q_{25}$ (первый квартиль) — значение, ниже которого лежит 25 % данных;
- $Q_{75}$ (третий квартиль) — значение, ниже которого лежит 75 % данных.

Между ними находится «центральная половина» данных. Её ширина — **межквартильный размах**:

$$IQR=Q_{75}-Q_{25}$$

Выбросом считается значение, которое отстоит от этой центральной части больше чем на $1{,}5\cdot IQR$. Метод не зависит от среднего и стандартного отклонения, а значит, сами выбросы почти не влияют на границы.

### Алгоритм по шагам

1. **Найти квартили** $Q_{25}$ и $Q_{75}$ (в задаче они заданы).
2. **Вычислить размах:** $IQR=Q_{75}-Q_{25}$.
3. **Построить границы:**

$$L=Q_{25}-1{,}5\cdot IQR,\qquad U=Q_{75}+1{,}5\cdot IQR$$

4. **Применить правило.** Значение $x$ — выброс, если $x<L$ или $x>U$. Значения в интервале $[L;U]$ считаются нормальными.

Множитель $1{,}5$ — стандартный выбор Тьюки. Множитель $3$ используют для поиска «далёких» (экстремальных) выбросов.

## Задача и данные

## Результаты

### Задание 1

Матрица попарных манхэттенских расстояний:

| | A | B | C | D | Сумма $S$ |
| - | :-: | :-: | :-: | :-: | :-: |
| **A** | 0 | 7 | 6 | 3 | **16** |
| **B** | 7 | 0 | 5 | 4 | **16** |
| **C** | 6 | 5 | 0 | 3 | 14 |
| **D** | 3 | 4 | 3 | 0 | 10 |

Пример расчёта: $d(A,B)=\lvert1-1\rvert+\lvert1-2\rvert+\lvert5-(-1)\rvert=0+1+6=7$.

Максимальная сумма равна 16 и достигается у двух объектов, поэтому **выбросы: A и B**. Самый «центральный» объект — D (сумма 10).

### Задание 2

$$IQR=5-2=3,\qquad L=2-1{,}5\cdot3=-2{,}5,\qquad U=5+1{,}5\cdot3=9{,}5$$

Нормальные значения лежат в интервале $[-2{,}5;\ 9{,}5]$, а выбросы — это все значения

$$x<-2{,}5\quad\text{или}\quad x>9{,}5$$

то есть интервалы $(-\infty;\,-2{,}5)$ и $(9{,}5;\,+\infty)$. Сами границы выбросами не считаются (в программе используются строгие неравенства).
