## Теоретическая часть

### Сверточный слой

Сверточный слой строится на двух идеях:

- **Локальная связность.** Каждый нейрон связан только с небольшой областью входа, размер которой равен размеру ядра.
- **Разделяемые веса.** Одно и то же ядро скользит по всему изображению. Параметров получается мало, а признак находится в любом месте кадра (инвариантность к сдвигу).

Результат работы слоя — **карта признаков**, которая показывает, где на изображении встретился признак, закодированный в ядре.

### Свертка

В позиции $(i,j)$ ядро $W$ размером $k\times k$ накладывается на вход $X$, элементы перемножаются и суммируются, затем прибавляется смещение $b$:

$$Z_{i,j}=\sum_{m=0}^{k-1}\sum_{n=0}^{k-1}X_{i+m,\ j+n}\cdot W_{m,n}+b$$

Для входа $N\times N$, ядра $k\times k$, шага 1 и без дополнения краёв размер выхода равен $(N-k+1)\times(N-k+1)$. Для входа $3\times3$ и ядра $2\times2$ это матрица $2\times2$, то есть 4 положения ядра.

### ReLU

$$a_{i,j}=\max(0,\,Z_{i,j})$$

Отрицательные значения обнуляются, положительные проходят без изменений. Без функции активации сколь угодно глубокая сеть сводилась бы к линейной регрессии. Производная ReLU равна 1 при $z>0$ и 0 при $z\le0$, поэтому градиент не затухает на положительных значениях и вычисляется мгновенно.

### Функция потерь

Среднеквадратичная ошибка в форме с множителем $\tfrac12$:

$$L=\frac12\sum_{i,j}\bigl(a_{i,j}-y_{i,j}\bigr)^2$$

Множитель $\tfrac12$ сокращается при дифференцировании, и производная упрощается до $a-y$.

## Алгоритм обучения

Одна итерация состоит из прямого прохода, обратного прохода и обновления параметров. Затем с новыми $W$ и $b$ всё повторяется.

### 1. Прямой проход

1. Свертка: $Z^{conv}_{i,j}=\sum_{m,n}X_{i+m,\,j+n}\cdot W_{m,n}$.
2. Смещение: $Z=Z^{conv}+b$.
3. Активация: $a=\max(0,Z)$.

### 2. Обратный проход

Ошибка зависит от параметров через цепочку $W,b\to Z\to a\to L$, поэтому градиенты находятся по правилу цепочки от конца к началу.

| Шаг | Формула | Смысл |
| :-: | :-----: | ----- |
| 1 | $\dfrac{\partial L}{\partial a}=a-y$ | Насколько и в какую сторону выход отличается от цели |
| 2 | $\dfrac{\partial L}{\partial z}=\dfrac{\partial L}{\partial a}\odot\begin{cases}1,&z>0\\0,&z\le0\end{cases}$ | Градиент проходит только через «включённые» нейроны |
| 3 | $\dfrac{\partial L}{\partial b}=\sum\limits_{i,j}\dfrac{\partial L}{\partial z_{i,j}}$ | $b$ добавлялось ко всем элементам, поэтому градиенты суммируются |
| 4 | $\dfrac{\partial L}{\partial W_{m,n}}=\sum\limits_{i,j}\dfrac{\partial L}{\partial z_{i,j}}\cdot X_{i+m,\,j+n}$ | Вес участвовал в каждой позиции ядра, умножаясь на «свой» пиксель |

### 3. Градиентный спуск

$$W^{new}=W^{old}-\alpha\,\frac{\partial L}{\partial W},\qquad b^{new}=b^{old}-\alpha\,\frac{\partial L}{\partial b}$$

Градиент указывает направление роста ошибки, поэтому его вычитают. Скорость обучения $\alpha$ задаёт размер шага:

- при слишком большом $\alpha$ обучение нестабильно, алгоритм «проскакивает» минимум;
- при слишком малом $\alpha$ обучение требует очень много итераций.

Обучение заканчивается, когда ошибка достаточно мала или выполнено заданное число эпох.

## Примеры аналитического расчёта

Во всех примерах: свертка $2\times2$ без дополнения краёв, шаг 1, ReLU, MSE, $\alpha=0{,}1$. Данные и результаты подробно расписаны в разделе 3 пособия.

### Пример 1. Три итерации

```text
X = [[2, 1, 0],     W = [[0.4, -0.4],     y = [[0.8, 0.8],
     [1, 2, 1],          [0.3, -0.2]]          [0.8, 0.8]]
     [0, 1, 2]]
b = 0.7
```

| Итерация | $L$ | $\partial L/\partial b$ | $W^{new}$ | $b^{new}$ |
| :------: | :-: | :---------------------: | :-------: | :-------: |
| 1 | 0,53 | 0,4 | `[0,32; −0,3 / 0,12; −0,28]` | 0,66 |
| 2 | 0,3124 | −1,04 | `[0,472; −0,112 / 0,14; −0,128]` | 0,764 |
| 3 | 0,6388 | 2,032 | `[0,1328; −0,2648 / −0,1136; −0,4672]` | 0,5608 |

(в записи матриц `/` разделяет строки).

Проверка после третьего обновления показывает все $Z<0$, поэтому $a=0$ и $L=1{,}28$. Это пример слишком большого шага: на третьей итерации выходы «перелетели» цель 0,8, и ReLU обнулил весь выход. Градиент стал нулевым, и сеть перестала обучаться («умирание ReLU»).

### Пример 2. Одна итерация, все нейроны активны

```text
X = [[2, 0, 2],     W = [[0.7, -0.1],     y = [[0.5, 0.5],
     [0, 2, 0],          [0.3, -0.2]]          [0.5, 0.5]]
     [2, 0, 2]]
b = 0.4
```

| $Z$ | $L$ | $\partial L/\partial b$ | $\partial L/\partial W$ | $W^{new}$ | $b^{new}$ |
| :-: | :-: | :---------------------: | :---------------------: | :-------: | :-------: |
| `[1,4; 0,8 / 0,8; 1,4]` | 0,9 | 2,4 | `[3,6; 1,2 / 1,2; 3,6]` | `[0,34; −0,22 / 0,18; −0,56]` | 0,16 |

После обновления ошибка уменьшается до $L=0{,}4264$.

### Пример 3. Одна итерация, часть нейронов выключена

```text
X = [[3, 2, 2],     W = [[0.3, -0.5],     y = [[0.6, 0.6],
     [0, 2, 3],          [0.5, -0.3]]          [0.6, 0.6]]
     [2, 3, 2]]
b = 0.2
```

| $Z$ | $L$ | $\partial L/\partial z$ | $\partial L/\partial b$ | $W^{new}$ | $b^{new}$ |
| :-: | :-: | :---------------------: | :---------------------: | :-------: | :-------: |
| `[−0,5; −0,1 / −0,7; 0,2]` | 0,62 | `[0; 0 / 0; −0,4]` | −0,4 | `[0,38; −0,38 / 0,62; −0,22]` | 0,24 |

Здесь ReLU пропускает градиент только через один нейрон (правый нижний), поэтому ошибка обучает веса только по одному положению ядра. После обновления $L=0{,}4894$.

## Программная реализация

Программа написана на чистом Python 3, без NumPy и фреймворков глубокого обучения. Матрицы представлены вложенными списками, все операции написаны явными циклами, поэтому код легко сверять с ручным расчётом.

| Функция | Что делает |
| ------- | ---------- |
| `convolution_2d` | Свертка матрицы с ядром с заданным шагом (без смещения) |
| `add_bias` | Добавляет $b$ к каждому элементу матрицы |
| `relu`, `relu_derivative` | Функция активации и её производная ($1$ при $z>0$, иначе $0$) |
| `mse_loss`, `mse_gradient` | Ошибка $L=\tfrac12\sum(a-y)^2$ и градиент $\partial L/\partial a=a-y$ |
| `elementwise_multiply` | Поэлементное произведение матриц (для $\partial L/\partial z$) |
| `sum_matrix` | Сумма элементов матрицы (для $\partial L/\partial b$) |
| `compute_weight_gradients` | Градиент по весам ядра $\partial L/\partial W$ |
| `update_parameters` | Шаг градиентного спуска для $W$ и $b$ |
| `train_step` | Одна полная итерация: прямой проход → ошибка → градиенты → обновление |
| `print_matrix` | Вывод матрицы, значения округляются до 4 знаков |

Скрипт в приложении А выполняет 4 итерации на данных примера 1, печатает промежуточные матрицы каждого шага ($Z_{conv}$, $Z$, $a$, $\partial L/\partial a$, $\partial L/\partial z$, $\partial L/\partial W$, $W^{new}$) и значение $L$. Ошибка в выводе относится к параметрам **до** обновления на этой итерации.

### Порядок выполнения

1. Выполнить прямой проход: найти $Z^{conv}$ (4 положения ядра), прибавить $b$, применить ReLU.
2. Вычислить $L$ и $\partial L/\partial a=a-y$.
3. Найти $\partial L/\partial z$ с учётом ReLU: для $z\le0$ градиент равен нулю.
4. Вычислить $\partial L/\partial b$ и $\partial L/\partial W$.
5. Обновить параметры и повторить шаги 1–5 ещё два раза.
6. Проверить результат программой, подставив данные варианта в `main.py` и изменив число итераций на 3.
7. В отчёте для каждой итерации привести значения $Z$, $L$, градиентов и новых параметров и сделать вывод о том, как менялась ошибка.

Полезно проверять расчёт по двум признакам: после обновления ошибка обычно должна уменьшаться, а если на какой-то итерации все $Z\le0$, градиенты нулевые и обучение остановилось.
