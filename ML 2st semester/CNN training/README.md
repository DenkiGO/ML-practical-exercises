## Сверточная нейронная сеть

### Идея

**Сверточные нейронные сети (CNN)** предназначены для данных с сетчатой структурой, прежде всего изображений. Вместо того чтобы связывать каждый вход с каждым нейроном, сверточный слой использует небольшое **ядро** (фильтр), которое скользит по изображению и в каждой позиции вычисляет взвешенную сумму пикселей под собой. Одни и те же веса применяются ко всем позициям, поэтому параметров мало, а найденный признак (например, край) распознаётся в любом месте картинки.

### Прямой проход

Слой состоит из трёх операций.

**1. Свертка.** Ядро $W$ размером $k\times k$ накладывается на входную матрицу $X$ с шагом $s$, и в каждой позиции $(i,j)$ перемножаются элементы и суммируются:

$$Z^{conv}_{i,j}=\sum_{m=0}^{k-1}\sum_{n=0}^{k-1}X_{i\,s+m,\ j\,s+n}\cdot W_{m,n}$$

Размер выхода для входа $H\times H$ без дополнения краёв:

$$H_{out}=\left\lfloor\frac{H-k}{s}\right\rfloor+1$$

Для входа $3\times3$, ядра $2\times2$ и шага $s=1$ получается матрица $2\times2$, то есть 4 положения ядра.

**2. Смещение.** К каждому элементу добавляется одно число $b$: $Z=Z^{conv}+b$.

**3. Активация ReLU.** Отрицательные значения обнуляются:

$$a=\max(0,\,Z)$$

### Функция потерь

Расхождение выхода $a$ с целевыми значениями $y$ измеряется среднеквадратичной ошибкой (в форме с множителем $\tfrac12$):

$$L=\frac12\sum_{i,j}\bigl(a_{i,j}-y_{i,j}\bigr)^2$$

## Алгоритм одной итерации обучения

Ошибка зависит от весов через цепочку $W,\,b\ \to\ Z\ \to\ a\ \to\ L$, поэтому градиенты находятся по правилу цепочки, двигаясь от конца к началу.

### 1. Градиент по выходу

$$\frac{\partial L}{\partial a_{i,j}}=a_{i,j}-y_{i,j}$$

### 2. Градиент через ReLU

Производная ReLU равна 1 там, где вход был положительным ($z>0$), и 0 в остальных местах ($z\le0$). Градиент по $z$ получается поэлементным умножением:

$$\frac{\partial L}{\partial z}=\frac{\partial L}{\partial a}\odot\frac{\partial a}{\partial z}$$

Здесь $\odot$ — поэлементное умножение. Нейрон, который «выключен» ReLU, не получает градиента.

### 3. Градиент по смещению

Смещение $b$ добавляется ко всем элементам, поэтому его градиент — сумма градиентов по всем позициям:

$$\frac{\partial L}{\partial b}=\sum_{i,j}\frac{\partial L}{\partial z_{i,j}}$$

### 4. Градиент по весам ядра

Вес $W_{m,n}$ участвовал в каждой позиции ядра, умножаясь на соответствующий пиксель. Поэтому его градиент — сумма произведений градиента позиции на тот пиксель, на который вес «смотрел»:

$$\frac{\partial L}{\partial W_{m,n}}=\sum_{i,j}\frac{\partial L}{\partial z_{i,j}}\cdot X_{i+m,\ j+n}$$

Фактически это свертка входа $X$ с матрицей $\dfrac{\partial L}{\partial z}$.

### 5. Обновление параметров

$$W^{new}=W^{old}-\alpha\,\frac{\partial L}{\partial W},\qquad b^{new}=b^{old}-\alpha\,\frac{\partial L}{\partial b}$$

где $\alpha$ — скорость обучения. Затем итерация повторяется с новыми параметрами.

## Задача и данные

Выполнить итерации обучения сверточного слоя. Свертка без дополнения краёв ($s=1$), активация ReLU, потери MSE.

```text
X = [[2, 1, 0],     W = [[0.4, -0.4],     y = [[0.8, 0.8],
     [1, 2, 1],          [0.3, -0.2]]          [0.8, 0.8]]
     [0, 1, 2]]
```

Начальное смещение $b=0{,}7$, скорость обучения $\alpha=0{,}1$.

## Программа

| Функция | Что делает |
| ------- | ---------- |
| `convolution_2d` | Свертка матрицы с ядром с заданным шагом (без смещения) |
| `add_bias` | Добавляет $b$ к каждому элементу матрицы |
| `relu`, `relu_derivative` | Функция активации и её производная ($1$ при $z>0$, иначе $0$) |
| `mse_loss`, `mse_gradient` | Ошибка $L=\tfrac12\sum(a-y)^2$ и градиент $\partial L/\partial a=a-y$ |
| `elementwise_multiply` | Поэлементное произведение матриц (для $\partial L/\partial z$) |
| `sum_matrix` | Сумма элементов матрицы (для $\partial L/\partial b$) |
| `compute_weight_gradients` | Градиент по весам ядра $\partial L/\partial W$ |
| `update_parameters` | Шаг градиентного спуска для $W$ и $b$ |
| `train_step` | Одна полная итерация: прямой проход → ошибка → градиенты → обновление |
| `print_matrix` | Вывод матрицы, значения округляются до 4 знаков |

Скрипт выполняет **4 итерации** подряд, передавая обновлённые $W$ и $b$ следующей. Ошибка $L$ в выводе относится к параметрам **до** обновления на этой итерации.

## Результаты

### Первая итерация

Прямой проход:

```text
Z_conv = [[ 0.3, 0.8],     Z = [[1.0, 1.5],     a = Z
          [-0.6, 0.3]]          [0.1, 1.0]]
```

Например, левый верхний элемент: $2\cdot0{,}4+1\cdot(-0{,}4)+1\cdot0{,}3+2\cdot(-0{,}2)=0{,}3$. Ошибка $L=0{,}53$.

Обратный проход: $\dfrac{\partial L}{\partial a}=a-y=$ `[[0.2, 0.7], [-0.7, 0.2]]`, все $Z>0$, поэтому $\dfrac{\partial a}{\partial z}=1$ и $\dfrac{\partial L}{\partial z}=\dfrac{\partial L}{\partial a}$. Тогда $\dfrac{\partial L}{\partial b}=0{,}4$, а для весов, например:

$$\frac{\partial L}{\partial W_{0,0}}=0{,}2\cdot2+0{,}7\cdot1+(-0{,}7)\cdot1+0{,}2\cdot2=0{,}8$$

Аналогично для остальных весов: $\dfrac{\partial L}{\partial W}=$ `[[0.8, -1.0], [1.8, 0.8]]`.

Обновление: $W^{new}=$ `[[0.32, -0.3], [0.12, -0.28]]`, $b^{new}=0{,}66$.

| 1 | `[1; 1,5 / 0,1; 1]` | 0,5300 | 0,4 | `[0,32; −0,3 / 0,12; −0,28]` | 0,6600 |
| 2 | `[0,56; 0,94 / 0,1; 0,56]` | 0,3124 | −1,04 | `[0,472; −0,112 / 0,14; −0,128]` | 0,7640 |

(в записи матриц `/` разделяет строки).

### Что произошло при $\alpha=0{,}1$

- **Итерация 2.** Ошибка уменьшилась с $0{,}53$ до $0{,}3124$, обучение идёт в нужную сторону.
- **Итерация 3.** Ошибка выросла до $0{,}6388$: шаг оказался слишком большим, и выходы $a$ «перелетели» цель $0{,}8$ в другую сторону (до $1{,}48$). Градиент $\partial L/\partial b=2{,}032$ сильно изменил параметры.
- **Итерация 4.** После третьего обновления все значения $Z$ стали отрицательными, ReLU обнулил весь выход, $a=0$ и $\partial a/\partial z=0$. Все градиенты стали нулевыми, веса перестали обновляться, а ошибка застыла на $L=\tfrac12\cdot4\cdot0{,}8^2=1{,}28$. Это явление называют **«умиранием ReLU»**: параметры не восстановятся, потому что градиент тождественно равен нулю.

### Влияние скорости обучения

Дополнительная проверка (не входит в скрипт): те же данные, 60 итераций при разных $\alpha$.

| :------: | :------------------: | :------------------: | :------------------: |
| 0,1 | 0,53; 0,3124; 0,6388; 1,28 | 1,28 | 1,28 (обучение остановилось) |

**Вывод.** Скорость обучения определяет, сойдётся ли обучение. При слишком большом $\alpha$ шаги перепрыгивают минимум, ошибка растёт, а ReLU может «умереть». При меньшем $\alpha$ ошибка монотонно убывает, но чем меньше шаг, тем медленнее сходимость. Для этой задачи $\alpha=0{,}05$ сходится быстрее всех из проверенных значений.
