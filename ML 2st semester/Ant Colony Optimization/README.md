## Муравьиный алгоритм

### Идея

**Муравьиный алгоритм (Ant Colony Optimization, ACO)** — метаэвристический метод, вдохновлённый поведением настоящих муравьёв. Муравей, идя от колонии к пище, оставляет на пути **феромон**. Другие муравьи охотнее выбирают тропы с большим количеством феромона, а на коротких путях он накапливается быстрее, потому что по ним успевает пройти больше муравьёв. Феромон со временем испаряется, поэтому плохие и случайные тропы забываются. Такой механизм косвенного общения через изменение среды называют **стигмергией**.

В задаче коммивояжёра (TSP) «тропы» — это рёбра графа, а «пища» — замкнутый маршрут минимальной длины, проходящий через каждый город ровно один раз.

### Параметры

| Параметр | Значение | Смысл |
| :------: | :------: | ----- |
| $\alpha$ | 1 | Вес феромона в выборе следующего города |
| $\beta$ | 2 | Вес эвристики (близости городов) |
| $\rho$ | 0,5 | Коэффициент испарения («забывчивости») феромона |
| $\tau_0$ | 1 | Начальное количество феромона на каждом ребре |
| $Q$ | 1 | Константа, определяющая количество откладываемого феромона |
| Муравьёв | 4 | По одному на каждый стартовый город |

## Алгоритм

За одну итерацию колония проходит три этапа: **построение маршрутов → оценка → обновление феромона**.

### 1. Инициализация

На всех рёбрах задаётся одинаковый феромон: $\tau_{ij}=\tau_0$. Пока следов нет, выбор определяется только расстояниями.

### 2. Построение маршрута одним муравьём

Муравей стартует в своём городе и повторяет шаг, пока не посетит все города. Города, в которых он уже был, запоминаются (список посещённых) и повторно не выбираются.

Из города $i$ муравей переходит в город $j$ с вероятностью

$$P_{ij}=\frac{\tau_{ij}^{\alpha}\cdot\eta_{ij}^{\beta}}{\sum\limits_{l\,\in\,\text{не посещённые}}\tau_{il}^{\alpha}\cdot\eta_{il}^{\beta}},\qquad \eta_{ij}=\frac{1}{L_{ij}}$$

где $L_{ij}$ — расстояние между городами, $\eta_{ij}$ — эвристическая привлекательность ребра (чем короче ребро, тем она выше), $\tau_{ij}$ — текущий феромон на ребре.

Числитель складывается из двух множителей: $\tau^\alpha$ отвечает за «опыт колонии», $\eta^\beta$ — за жадную близость. При $\alpha=1,\ \beta=2$ получается $\tau_{ij}\cdot\dfrac{1}{L_{ij}^{2}}$, поэтому расстояние влияет на выбор сильнее феромона. После посещения всех городов муравей возвращается в стартовый.

> В расчёте и в программе выбирается **наиболее вероятный** город (максимум числителя), то есть алгоритм в такой постановке детерминирован. В классическом ACO следующий город выбирается случайно в соответствии с вероятностями $P_{ij}$.

### 3. Длина маршрута

После завершения цикла вычисляется его длина — сумма длин всех пройденных рёбер:

$$L_k=\sum L_{ij}$$

### 4. Обновление феромона

Когда все муравьи закончили обход, феромон обновляется в два шага.

**Испарение** умножает феромон на всех рёбрах на $(1-\rho)$, чтобы старые следы постепенно исчезали.

**Откладывание** добавляет феромон на рёбра, по которым прошли муравьи. Чем короче маршрут, тем больше добавка:

$$\Delta\tau=\frac{Q}{L_k}$$

Итоговая формула для ребра $(k,j)$:

$$\tau_{kj}^{new}=(1-\rho)\,\tau_{kj}^{old}+\sum_{\text{муравьи}}\Delta\tau$$

Рёбра короткого маршрута, пройденные несколькими муравьями, накапливают больше феромона и привлекают колонию на следующей итерации. Рёбра, которыми никто не воспользовался, только испаряются.

### 5. Повторение

Итерации повторяются заданное число раз (здесь 2). Лучшим решением считается самый короткий найденный маршрут.

### Псевдокод

```text
τ[i][j] ← τ0 для всех рёбер
для каждой итерации:
    для каждого муравья (старт = его город):
        маршрут ← [старт]
        пока не посещены все города:
            i ← последний город маршрута
            для каждого непосещённого j:  score[j] ← τ[i][j]^α · (1/d[i][j])^β
            j* ← выбор по score (максимум или случайно по вероятностям)
            добавить j* в маршрут
        замкнуть маршрут в старт, посчитать длину
    τ ← (1 − ρ) · τ
    для каждого маршрута, для каждого его ребра (i, j):  τ[i][j] += Q / длина
```

### Чем ACO отличается от полного перебора

| | Полный перебор | Муравьиный алгоритм |
| - | :------------: | :-----------------: |
| Результат | Гарантированно оптимальный | Хороший, но без гарантии оптимума |
| Число маршрутов | $(n-1)!/2$ различных циклов | $m$ муравьёв × число итераций |
| Применимость | Только малые $n$ | Подходит и для больших графов |

## Задача и данные

Граф из 4 городов A, B, C, D. Матрица расстояний:

```text
        A  B  C  D
    A [ 0, 5, 6, 8 ]
    B [ 5, 0, 7, 2 ]
    C [ 6, 7, 0, 4 ]
    D [ 8, 2, 4, 0 ]
```

Требуется выполнить 2 итерации алгоритма, после каждой сравнить найденную длину с результатом полного перебора и построить граф.

## Программа

| Элемент | Что делает |
| ------- | ---------- |
| `dist` | Матрица расстояний между городами |
| `alpha, beta, rho, tau0, ants` | Параметры алгоритма |
| `pheromones` | Матрица феромона $n\times n$, изначально заполнена $\tau_0$ |
| `scores` | Значения $\tau^\alpha\cdot(1/d)^\beta$ для непосещённых городов |
| `solve_aco` | Выполняет итерации: строит маршруты всех муравьёв, затем обновляет феромон |

Каждый муравей стартует в «своём» городе (`start_node` от 0 до 3) и на каждом шаге берёт город с максимальным `score`. Расстояние маршрута считается по замкнутому пути. Феромон обновляется в конце итерации: сначала `pheromones *= (1 - rho)`, затем к каждому ребру маршрута прибавляется `1.0 / d`. После каждой итерации выводится длина лучшего маршрута.

## Результаты

### Итерация 1

Феромон на всех рёбрах равен $\tau_{ij}=1$, поэтому выбор определяется только расстояниями. Для муравья 1 (старт A):

| Переход | $\tau\cdot 1/d^2$ | Вероятность |
| :-----: | :---------------: | :---------: |
| A → B | $1/25=0{,}04$ | 0,48 |
| A → C | $1/36=0{,}0278$ | 0,33 |
| A → D | $1/64=0{,}0156$ | 0,19 |

Выбирается B. Затем из B доступны C (0,075) и D (0,925), выбирается D, остаётся только C. Маршрут: A→B→D→C→A.

Маршруты всех муравьёв:

| Муравей | Старт | Маршрут | Длина |
| :-----: | :---: | ------- | :---: |
| 1 | A | A → B → D → C → A | 17 |
| 2 | B | B → D → C → A → B | 17 |
| 3 | C | C → D → B → A → C | 17 |
| 4 | D | D → B → A → C → D | 17 |

Все муравьи пришли к одному циклу длиной 17.

**Проверка полным перебором** (всего $(4-1)!=6$ маршрутов при фиксированном старте A):

| Маршрут | Длина |
| ------- | :---: |
| A → B → C → D → A | 24 |
| **A → B → D → C → A** | **17** |
| A → C → B → D → A | 23 |
| **A → C → D → B → A** | **17** |
| A → D → B → C → A | 23 |
| A → D → C → B → A | 24 |

Минимальная длина равна 17, то есть найденный муравьями маршрут **оптимален**.

**Обновление феромона.** Ребро входит в цикл A–B–D–C–A, и по нему прошли 4 муравья (каждый добавляет $1/17$):

$$\tau^{new}=(1-0{,}5)\cdot1+4\cdot\frac{1}{17}=0{,}5+0{,}2353=0{,}7352$$

Рёбра AB, BD, DC, CA получают $0{,}7352$. Рёбра AD и BC, по которым никто не шёл, только испаряются: $\tau^{new}=0{,}5\cdot1=0{,}5$.

### Итерация 2

Теперь феромон на рёбрах неодинаков, и это сдвигает вероятности в пользу короткого цикла. Для муравья 1 (старт A):

| Переход | $\tau\cdot 1/d^2$ | Вероятность |
| :-----: | :---------------: | :---------: |
| A → B | $0{,}7352/25=0{,}0294$ | 0,51 |
| A → C | $0{,}7352/36=0{,}0204$ | 0,35 |
| A → D | $0{,}5/64=0{,}0078$ | 0,14 |

Выбор по-прежнему B, далее D (0,95) и C. Остальные три муравья также повторяют цикл длиной 17. Полный перебор снова даёт минимум 17.

Обновление феромона:

$$\tau^{new}=0{,}5\cdot0{,}7352+\frac{4}{17}=0{,}6029\quad\text{(рёбра AB, BD, DC, CA)}$$

$$\tau^{new}=0{,}5\cdot0{,}5=0{,}25\quad\text{(рёбра AD, BC)}$$

### Сводка

| Итерация | Лучшая длина | Оптимум (перебор) | Феромон на рёбрах цикла | Феромон на AD, BC |
| :------: | :----------: | :---------------: | :---------------------: | :---------------: |
| 1 | 17 | 17 | 0,7352 | 0,5 |
| 2 | 17 | 17 | 0,6029 | 0,25 |

Вывод программы:

```text
Итерация 1, Лучшая длина: 17
Итерация 2, Лучшая длина: 17
```

### Что произошло

- **Итерация 1.** Феромон одинаков, поэтому муравьи руководствуются только расстояниями. Из-за жадного выбора ближайших городов, например B→D с длиной 2, все четыре маршрута сошлись к одному оптимальному циклу.
- **Итерация 2.** Феромон на рёбрах оптимального цикла ($0{,}7352$) в 1,5 раза превышает феромон на остальных рёбрах ($0{,}5$), и вероятность выбора правильных переходов выросла (например, A→B: с 0,48 до 0,51; B→D: с 0,925 до 0,95). Результат не изменился, но решение закрепилось.
- **Испарение** постепенно ослабляет все следы, а добавка $4/17$ подпитывает только те рёбра, по которым реально шли муравьи. Феромон на неиспользуемых рёбрах AD и BC упал в 4 раза: $1\to0{,}5\to0{,}25$.
